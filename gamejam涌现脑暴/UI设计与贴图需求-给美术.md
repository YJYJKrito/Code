### 1.2 像素规格

| 项 | 要求 |
|---|---|
| 风格 | 16–32 bit 像素（参考你们的角色小人） |
| 像素格 | **2px 一格**（1920×1080 下） |
| 描边 | 深色外描边 1–2 格，**不要抗锯齿**（导入时 Point 过滤） |
| 圆角 | 木框 **8–12px** 圆角，像素做阶梯 |
| 高光 | 左上来光，右下阴影（和角色一致） |
| 材质 | 木纹、羊皮纸纤维，**不要干净渐变** |

### 1.3 尺寸基准

- 设计稿 **1920 × 1080**（横屏）
- 手机端 16:9 缩放，左右安全区 120px
- 导出 1x + 2x，Unity PPU = 64，**Point 过滤 + 无 Mipmap**

### 1.4 双平台

| 约束 | 要求 |
|---|---|
| 触控 | 可点元素 ≥ **88×88** |
| 手机无 hover | normal / pressed 必须能区分 |
| 字号 | 正文 ≥ 28px，数字 ≥ 32px |

## 6. 命名与导出

```
ui_<类别>_<名字>_<状态>@<倍率>.png

ui_panel_parchment@1x.png
ui_btn_wood_hover@1x.png
ui_badge_granary@2x.png
```

| 项 | 要求 |
|---|---|
| 格式 | PNG 带 Alpha |
| 过滤 | Point（像素图），导入时关闭 Mipmap |
| 9 宫格 | 文件名加 `_9s`，注明 border |
| 描边 | 画进图里（深色外描边），不要用 Unity 外发光 |
| 背景 | 透明（`bg_*` 除外） |

## 8. 不要做的事

| ❌ | 原因 |
|---|---|
| 贴图里画字 | 程序用 TMP 渲染，本地化会废 |
| 抗锯齿/模糊 | 和现有像素小人冲突 |
| 暗色/水墨/写实 | 和现有明亮画风冲突 |
| 另起一套配色 | 沿用 §1.1 的类别色 |
| 一张图放多个元素 | 程序按文件切 |
| 把阴影烘焙死 | 程序统一做投影 |
