# 评分影响因素清单


> ⚠ **历史底稿（30 年 / 50 年扫参时代）**：评分公式与移民/流民法的关系已随 10.19 修复改变。当前实现见 [当前机制真实规格-修复版.md](当前机制真实规格-修复版.md) 第 9 节，回归见 [回归对比-10.19修复.md](回归对比-10.19修复.md)。

> 给「固定时间（50 年）」和「目标分数」两种模式做设计前的底稿。
> 实测数据：30 年 = 20 种子 × 9 玩法；50 年 = 10 种子 × 9 玩法。

---

## 0. 评分公式回顾

```
life    = clamp(personYears × 100 / 1200, 0, 100)      // 存续
welfare = clamp(100 − 2×平均饥饿 − 饥荒月/2, 0, 100)     // 温饱
total   = (life × 70 + welfare × 30) / 100
```

**一共只有三个输入**：`personYears`、`平均饥饿`、`饥荒月数`。

下面所有东西，都是通过影响这三个输入来影响评分的。

---

## 1. 直接输入（3 个）

| 输入 | 定义 | 30 年实测 p50 / p90 / max | 50 年实测 p50 / p90 / max |
|---|---|---|---|
| 人年 | 每月人口累加 / 12 | 685 / 935 / 1250 | **880 / 1480 / 2015** |
| 平均饥饿 | 月度平均饥饿的均值 | 16 / 25 / 30 | — |
| 饥荒月 | 平均饥饿 ≥ 40 的月数 | 2 / 43 / 94 | — |

> **50 年的关键变化**：人年 p75 已经 **1185**，p90 **1480** —— 1200 的满分线会**大面积饱和**。

## 2. 影响「人年」的四条流量

```
人年 = ∫ 人口 dt ≈ 初始人口 + Σ出生 − Σ死亡 + Σ移民
```

### 2.1 出生（最大的正项）

| 杠杆 | 数值 | 谁控制 |
|---|---|---|
| 生育窗口 | 女 18–42 岁 | 随机（初始年龄） |
| 饥饿 < 60、恐惧 < 70 | 硬门槛 | **玩家**（粮/恐惧） |
| 子女上限 | 6（构建）/ 12（测试台） | 玩家（法条） |
| 婚育补贴(8) | 提高出生率 | **玩家** |
| 幼童口粮(9)、医药(12) | 降低夭折 → 抬高存活子女 | **玩家** |
| 出生冷却 | 每对夫妻的间隔 | 固定 |
| 配对 | 第一个合格男性，与年龄差无关 | 固定 |

**实测**：生育系 (8+9+12) 人年 572，和默认 831 比**没有更高** ——
因为多生的孩子也多吃，且夭折率仍高。**出生不是免费的。**

### 2.2 死亡（最大的负项）

| 死因 | 触发 | 谁控制 |
|---|---|---|
| 饥饿 | 饥饿 ≥ 99 | **玩家**（粮/济贫/幼童口粮） |
| 惊吓 | 恐惧 ≥ 99 | **玩家**（安抚/宵禁/祭祀） |
| 寿终 | 年龄判定 | 随机 |
| 夭折 | 幼儿概率 | 玩家（医药/幼童口粮） |
| 法律处决 | 减口/刑戮/逐客等 | **玩家** |
| 事件 | 疫病/边患/民变/匪患 | 部分（职业/对口法） |

**实测**：30 年累计死亡 p50 = 195；出生 p50 = 151 —— **死亡多于出生**，
村子本身是**慢性萎缩**的。撑住人口主要靠**移民**。

### 2.3 移民（当前最被低估的正项）

```csharp
if (tick % 2400 == 0 && CountAlive < 25 && granary > 20)
    AppendImmigrant ×2;
```

- **无条件**、不看玩法、不看法律
- 人口掉到 25 以下就补

**实测**：不装法 586 人年 → 流民法 948 人年（+62%），**这 +62% 几乎全部来自移民**。
**所以「移民流」是当前最强的人年杠杆，而且玩家什么都不用做。**

### 2.4 初始人口

固定 ~20 人（Bootstrap）。**对分数有影响，但玩家不可控。**

## 3. 影响「温饱」的三条

### 3.1 产出

```
产出 = 劳动力 × 5 × 耕地系数 + 勤勉/懒散 + 耕作(5) + 劳役(11)
```

| 杠杆 | 说明 |
|---|---|
| **劳动力** | 10 岁以下 0、10–16 半、60+ 半、饥饿减半 |
| **童工(39)** | 10 岁以下也能上工 → 直接加劳动力 |
| **耕地** | 开垦(71)加地；退化减地；arableBaseline 影响系数 |
| **耕作(5)/劳役(11)** | 直接加产出 |

### 3.2 消耗

```
消耗 = 人口/3 + 各户分粮（成人 8 / 幼儿 4，上限 20/10）
```

**人口越多，消耗越大** —— 这是「人年」和「温饱」之间的天然张力。

### 3.3 分配

| 杠杆 | 说明 |
|---|---|
| 粮仓预留线 40 | 低于它就不再分粮（保种子） |
| 济贫(1) | 饥饿 >45 可吃公仓 |
| 幼童口粮(9) | 儿童可吃公仓（**已修：只能吃预留线以上的**） |
| 买粮(26)/平粜(29)/常平(51) | 用钱换粮 |
| 屯粮(30)/售粮(31) | 公仓 ↔ 私粮 |

|---|---|---|---|
| 1 | **移民** | 人年 +62% | 不装法 52 → 流民法 **82** |

## 6. 对两种模式的影响

### 6.1 改成 50 年

**实测对比（同样玩法）：**

| | 30 年 | **50 年** |
|---|---|---|
| 灭村率 | 16% | **37%** |
| 年末人口 p50 | 15 | **5** |
| 人年 p50 | 685 | **880** |
| 人年 p90 | 935 | **1480** |
| 总评 p50 | 55 | 58 |
| 总评 p90 | 77 | **97（顶格）** |

**两个必须处理的问题：**

1. **1200 的满分线失效** —— 50 年 p75 就有 1185。要重定，建议 **2000**。
2. **村子是慢性萎缩的** —— 50 年末人口中位只有 5，靠移民续命。
   50 年不是"更长的好局"，是"更长的衰败"。**要么接受这个基调，要么调平衡。**

### 6.2 「达到分数就结算」模式 —— **有一个结构性问题**

**人年是单调递增的。** 所以：

```
「达到 60 分就结束」 ≈ 「活到 22 年就结束」
```

**它不会变成一个不同的玩法，只会变成一个不同的计时器。**

要让这个模式真正成立，必须让分数**不是时间的单调函数**。三种改法：

| 方案 | 怎么算 | 效果 |
|---|---|---|
| **A. 快照分** | 用**当前**人口/饥饿，而不是累计 | 必须尽快把村子做大；掉人=掉分 |
| **B. 速率分** | `人年 / 已过年数`（平均人口） | 比的是"维持效率"，不是时长 |
| **C. 可扣分** | `人年 − 惩罚×饥荒月 − 惩罚×死亡` | 分数会涨也会跌，需要同时管两头 |
| **D. 混合** | 快照分 + 速率分 | 既有爆发又有稳定 |

**我的建议**：如果目标是「速通」，用 **B 速率分**（"多少年达到平均人口 X"）；
如果目标是「高压经营」，用 **C 可扣分**（分数会跌，必须一直管）。

---

## 7. 一句话

> **评分只有三个输入：人年、平均饥饿、饥荒月。**
> **能大幅改变人年的只有两件事：移民、法条组合。**
> **恐惧和威信不进评分 —— 它们只是手段。**
>
> **而"达到分数就结束"必须改分数结构，否则它只是换个方式数日子。**
