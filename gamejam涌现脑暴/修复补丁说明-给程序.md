## 0. 为什么会有这份补丁

10.19 包体里有几类“不报错、只是安静地让游戏不对”的问题：

1. 全局条件法按**每个存活村民**各触发一次，效果 ×人口；立威能一 tick 全灭，阴气/共井直接抹掉饥饿。
2. `lawStrength` 只被 DSL 法读取，44/45/46/47/49 改的全是脚本法，整族是死代码。
3. PC 端模式选择只接受 `tick == 0` 的第一帧按键，实际选不了。
4. 屠者把“被归因到某条法的饿死”也算成处决。
5. 流民法不控制移民；高压村力用的是硬阈值人数，不是设计里的加权健康人口。
6. 主菜单 `Awake` 有一处空引用，会中断后面的按钮绑定。
7. 卡面条件文案与 ×70 后的实际阈值不一致。

全部在测试台 20 种子 × 15 玩法上回归过。

## 1. 引擎层改动（最重要）

### 1.1 全局条件法每 tick 只触发一次

`LawEngine` 新增：

```csharp
IsSharedOrTotalField(LawField)
IsGlobalCond(LawCond)
IsGlobalLaw(LawDefinition)
```

`Tick` 主循环里：

```csharp
bool globalLaw = IsGlobalLaw(lawDefinition);
...
if (data.villagerAlive[j] && AllCondsPass(...))
{
    ApplyAll(...);
    ...
    if (globalLaw) break;   // 全局法只跑第一个存活者
}
```

判定规则：

- `SelfGt/SelfLt/SelfEq` 读 `Granary/Treasury/Prestige/TotalDeaths/TotalBirths/InfantDeaths/ObituaryCount` 时算全局。
- `NeighborGt/NeighborRelative/NeighborDiedThisTick` 永远算自身依赖。
- 其余 15 种条件算全局。

### 1.2 guard 改为“筛目标 + 快照”

- `ApplyEffect`：`All/Neighbors` 不再在源头判 guard；`Self/共享` 仍在源头判。
- `AddToScope / SetInScope / DrainFromSelf / FillTo / ModifyBirthCooldown / Broadcast` 的每个目标写之前调用 `TargetGuardPasses(d, target, e)`。
- 新增 `SnapshotGuardState`：每条法触发前快照村民/资源；`GuardPasses/TargetGuardPasses` 读快照（`ReadGuardField`）。
  - 修掉「示众先 −20 再 +2」「常平先扣税库再判税库」「丁税宏观先扣金币再判金币」的连锁误判。
- 新增 `AnyAliveGuardPasses`：共享作用域的 guard 读逐人字段时，检查是否**存在**满足者。

### 1.3 废止语义

`LawEngine` 新增：

```csharp
public static int LawStrengthValue(VillageSaveData d, int lawId)
public static bool IsLawActive(VillageSaveData d, int lawId)  // strength > -100
```

- `Tick` / `RunDeathEffects` 跳过强度 ≤−100 的法（否则 `KillMaxOf/KillYoungest` 无视 Scale 仍会杀人）。
- `ModifyStrength` 不允许把已废止的法用正数“复活”。
- 所有 `HasLaw` / `ObitRules.SlotOf` 改为走 `IsLawActive`。
- 换成不同法时把该槽 `lawStrength/lawCooldown` 清零（`LawSelectionController.SelectVisible`）。

### 1.4 脚本法接入 lawStrength

`VillageLifecycleService` 新增：

```csharp
ScaleByLaw(data, lawId, value)
```

已接入：

| 法 | 位置 | 缩放 |
|---|---|---|
| 济贫 1 | 取粮的饥饿 −4 / 公共消耗 +pop/8 | `ScaleByLaw(1, ...)` |
| 税收 3 | 金币 −12 / 粮仓+3 / 税库+3 | `ScaleByLaw(3, ...)` |
| 耕作 5 | 产出 +pop/4 | `ScaleByLaw(5, ...)` |
| 劳役 11 | 产出 +pop/5 / 饥饿 +2 | `ScaleByLaw(11, ...)` |
| 医药 12 | 夭折 −3 / 寿终 −5 | `ScaleByLaw(12, ...)` |
| 幼童口粮 9 | 夭折 −4 | `ScaleByLaw(9, ...)` |

### 1.5 新增两个效果 kind

`LawEffectKind` 追加：

```csharp
BoostOtherLaws,        // 48 威权：其他活跃法强度 +amount
DisableStrongestLaw    // 49 赦令：废止强度最高的其他活跃法（全 0 时取第一个其他槽；无候选不生效）
```

`ApplyEffect` 对应分支：`BoostOtherLaws(d, slot, num)`、`DisableStrongestLaw(d, slot)`（返回被废法名，写入 `result.eventText`）。
`DisableLaw` 改为直接置 −100（`DisableLawById`）。

## 2. 模拟层改动

| 问题 | 改动 |
|---|---|
| 屠者把饿死算处决 | `VillagerProfessions.OnDeath`：`if (cause == "律法") executions++`（删掉 `lawIndex >= 0 ||`） |
| 流民法不控制移民 | `SimulateTick`：基础移民每 2400 tick +2；装法 17 时 +3；仍要求人口 <25、粮仓 >20 |
| 高压村力 | `RunRules.HealthyPop`：改为 `Σ max(0, 100−饥饿) / 100`（不再数“饥饿<50 且恐惧<50 的人数”） |
| 期满 tick | `SimulateTick`：`tick++` 后逐 tick 检查 `runMode>=0 && tick>=146104` → endKind 4 / Grade |
| 死亡数可见性 | `LawEngine.Tick` 用 `deathsSeen` 把前面法条击杀累加；`SimulateTick` 再把 `VillageEvents` 的讣告增量并进 `deathsThisTick`，哭丧/厚葬能看到天灾死亡 |
| OnDeath 停摆 | `RunDeathEffects` 改用 `LawEngine.IsLawActive`（含 prestigeSuspended 与 −100） |
| 沙盒结算 | `RunRules.Tick` 对 runMode<0 也累计人年/温饱；结算面板显示等级/总评/人年；人口归零仍判绝户 |
| 废止法维持费 | 威信维持费/存档摘要只统计 `IsLawActive` 的法 |

## 3. UI / 可见性改动

### 3.1 模式选择

`VillageUiController` 新增 `_runModeChosen`：

- 未选模式时 `UpdateSimulation` 直接 return（模拟暂停）。
- `HandleRunModeChoice` 不再要求 `tick == 0`：`1` 五十年、`2` 高压、`3` 沙盒；每 4 秒重显提示。
- 加载已有存档（tick>0 或 runMode≥0）视为已选。
- 移动端仍自动选五十年。
- subtitle UI 缺失时 10 秒后自动回退沙盒并写 warning，避免静默冻结。

### 3.2 HUD

`BuildStatusWord`：

- 高压：`高压 {V}/45 · 维持 {年}年{月}月`
- 五十年：`五十年 {年}年 · {总评} {等级}`
- 沙盒：`沙盒 · 人口归零结束`

### 3.3 事件点名

`VillageEvents.BuildBurstText(data, id)`：按事件检查实际生效的对口法/职业，在 `Bursts[id]` 后追加一句，例如：

- 蝗灾 + 耕作：`你写的『耕作』保住了半仓粮。`
- 疫病 + 医师：`村里的医师拦住了大半。`
- 边患 + 兵役征召：`你写的『兵役征召』把人挡在了村外。`

`Tick` 里 `eventText = BuildBurstText(data, num2)`。

### 3.4 主菜单空引用

`MainMenuController.Awake` 原来直接 `continueButton.onClick...`，任一处为空就中断后面全部绑定。
改为：

- 新增 `BindClick(Button, UnityAction)`；
- 所有按钮引用判空；
- `slots[]` 逐项判空；
- `versionLabel` 判空；
- 新增 `ResolveMissingReferences()` + `FindComponent<T>(name)` 兜底；
- `Update` 里 `confirmPanel` 判空；
- `RefreshMainMenu/RefreshSettings` 逐字段判空；
- `RefreshSlots/ContinueGame/OpenSlots/ShowConfirmation` 的空引用也全部判空。
