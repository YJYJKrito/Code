> 全部从反编译源码里抄的，不是猜的。行号省略了，你在工程里搜名字就能定位。

## 0. 先说一句最重要的

**目标机制只能建立在"会动的参数"上。**

现在游戏里有 40 多个被追踪的状态量，但其中**大部分在一局里其实是钉死的**（上一轮《信息缺口审计》里已经量过一次）。所以这份表分两部分：

- **§1–§9：全部参数**（有什么）
- **§10：哪些真的会动**（能拿来做什么）← **先看这一节**

## 4. 四条生死线

### 4.1 饥饿死
`hunger ≥ 99` → 死，死因「饥饿」

### 4.2 惊吓死
`fear ≥ 99` → 死，死因「惊吓」

### 4.3 寿终（★ 曲线在这儿）
```
每年判一次：
  年龄 < 60            → 0%
  否则  概率 = (年龄−60)² × 100 / 3500 ，上限 20%
```
| 年龄 | 60 | 65 | 70 | 75 | 80 | 85 | 90+ |
|---|---|---|---|---|---|---|---|
| 年死亡率 | 0% | 0% | 2% | 6% | 11% | 17% | **20%** |

法条「医药」−5，词条「病弱」×1.15、「强健」×0.85，烙记「劳损」年龄 +7。

### 4.4 夭折（年龄 < 3）
每 **120 tick** 判一次：

```
基准 2
+ 饥饿 > 50        → +(饥饿−50)/3
+ 恐惧 > 55        → +(恐惧−55)/4
+ 私粮 < 2         → +2
+ 粮仓 < 20        → +3
− 法条「幼童口粮」  → −4
− 法条「医药」      → −3
+ 词条「病弱」      → +2
− 词条「强健」      → −2
+ 烙记「绝粮」      → +2
− 烙记「用药」      → −3   ⚠ 该烙记从不设置
钳到 1 – 30
```

## 5. 生育

**每 240 tick 一次。**

**全局门槛**（任一不满足就整体不生育）：
```
粮仓 ≥ 30     且     存活人口 < 80
```
> ⚠ `80` 是**写死的字面量**，`VillageSaveData.MaxPopulation` 那个常量没人用。

**基础概率**
```
40%
+ 法条「婚育补贴」      +35
− 法条「宵禁」          −15
粮仓 > 180 且有婚育补贴 → 直接 100
粮仓 > 150              +12
粮仓 < 70               −25
钳到 5 – 100
```

**母亲条件**（`CanGiveBirth`）
```
女 · 18–42 岁 · 冷却 ≤ 0 · 子女 < 6 · 饥饿 < 60 · 恐惧 < 70
（私粮 < 2 时还要求粮仓 ≥ 6）
词条「难育」直接否
```

**父亲条件**（`FindPartner`，**返回第一个满足的男性**）
```
男 · 18–55 岁 · 饥饿 < 75 · 恐惧 < 80
⚠ 不看冷却
```

**个人概率**：`词条「多产」+20`，`烙记「绝粮」−20`，`烙记「服丧」−15`（⚠ 从不设置），钳 5–100

**成功之后**：粮仓 −12，母亲冷却 **480**（⚠ 现在写成 `? 480 : 480`，多产无效）

## 6. 词条与烙记

### 6.1 先天词条（8 条轴，16 个位）

**轴**：每人生成时抽 **1–2 条轴**，每条轴二选一。

| 轴 | 正 | 反 | 效果 |
|---|---|---|---|
| 1 | 怯懦 `1` | 果决 `2` | 恐惧基准 +18 / −7 |
| 2 | 贪婪 `4` | 慷慨 `8` | 抢钱更多 / ⚠ **慷慨无效果** |
| 3 | 勤勉 `16` | 懒散 `32` | 村产 ±2×人数 |
| 4 | 病弱 `64` | 强健 `128` | 饿得快 / 夭折↑ / 老死↑ |
| 5 | **多产 `256`** | 难育 `512` | 生育 +20% / 直接不能生 |
| 6 | 节俭 `1024` | 挥霍 `2048` | 省粮 / 吃双份 |
| 7 | 合群 `4096` | 孤僻 `8192` | ⚠ **整条轴无效果** |
| 8 | 坚韧 `16384` | 脆弱 `32768` | 恐惧涨得慢 |

> ⚠ **慷慨 / 合群 / 孤僻三个完全没实现**，但会显示在村民卡面上。

### 6.2 烙记（19 位）

**实际会发生**：只有 **「绝粮」`256`** 和 **「惊魂」`512`**。

| 位 | 名字 | 什么时候打上 |
|---|---|---|
| 256 | 绝粮 | 饥饿 ≥ 90 |
| 512 | 惊魂 | 恐惧 ≥ 90 |
| 1024 | 劳损 | ⚠ 要求先有「Corvee」，而它从不设置 → **拿不到** |
| 其余 16 个 | 罪人/劫匪/逃兵/绝户/守寡/光棍/债户/徙民/积怨/屠者/尸亲/恩主/巫祝/Corvee/用药/服丧 | ⚠ **全部拿不到** |

> `RemoveMark` 全工程零调用 → **烙记一旦打上，再也去不掉**。

## 10. ★ 哪些参数在一局里真的会动 ★

**这是做目标机制时最该先看的一节。**

| 参数 | 会动吗 | 依据 |
|---|---|---|
| **人口** | ✅ 会（24 → 0–80）| 实测：不同法条组下 30 年存活 1.7 – 31.6 人 |
| **粮仓** | ✅ 会 | 唯一有大幅起伏的寄存器 |
| **威信** | ✅ 会 | 会归零停摆 |
| **税库** | ✅ 会 | 但只有几种法条碰它 |
| **讣告数 / 累计死亡** | ✅ 会 | 直接计数 |
| **累计出生** | ✅ 会 | 直接计数 |
| **耕地格数** | ✅ 会 | 开垦 + 退化 |
| **饥饿** | ❌ **基本不会** | **推理**：只要粮仓 > 40，村民每次进食 −5 饥饿，而进食间隔 16 tick、饥饿只涨 1/32 tick → 饥饿永远压在地板上。**「饥饿致死」这条路基本不触发。** |
| **恐惧** | ⚠ 只在装了恐惧系法条时 | **回归到个人基准**（12 / 怯懦 30 / 果决 5 / 惊魂 22），不装法条就一路降到基准 |
| **金币** | ⚠ 早期会，后期趋平 | 需要灌法条维持 |
| **私粮** | ❌ 基本恒为 8 | 粮仓一直够，永远被补满 |
| **子女数** | ✅ 会 | 但上限 12，人多会到 |
| **年龄** | ✅ 会 | 单调 |
| **词条** | ❌ 终身不变 | 只有出生时抽 |
| **烙记** | ⚠ 只有「绝粮」「惊魂」会出现 | 且**永不消除** |
| **tyrantMode** | ❌ 永远 false | 死字段 |
| **粮仓上限** | ❌ 永远 500 | 没有任何东西能提高 |

**结论**：一局里真正"活着"的大参数只有 **人口 / 粮仓 / 威信 / 讣告数 / 耕地** 五个。其余要么恒定，要么只会单向下滑。

> ⚠ **这一栏里有几条是"推理"不是"实测"**（尤其饥饿和私粮）。如果你要拿它们做目标，我可以用 30 年 × 120 种子的扫描跑一遍，把每条参数在整个过程里的**最小/最大/是否碰到上下限**全部量出来。那会是一份更适合设计用的表。

## 11. 现成可算、但没人算过的派生量

这些数据**全都在存档里**，只是没有任何地方聚合过。做目标机制可以直接用：

| 派生量 | 从哪算 |
|---|---|

| **每篇讣告对应的法名** | 同上 |
| 各死因占比 | `obituaryCauses[]` 计数 |
| 幼儿夭折数 | `obituaryInfants[]` 计数 |

| 贫富分化（金币方差） | 逐人遍历 |
| 「哪一年最难」 | 需要新加累加 |

## 12. 一句话

> **能动的只有五个：人口、粮仓、威信、讣告数、耕地。**
> **其余 30 多个状态量在一局里要么恒定，要么只会单向下滑。**
>
> **要设计目标，先把地基踩在会动的那五个上面。**
