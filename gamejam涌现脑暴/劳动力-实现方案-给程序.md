# 劳动力 · 实现方案 — 给程序

> **一句话**：产出从「**人口** × 4」改成「**劳动力** × 5」。
> 劳动力按**年龄**和**饥饿**折算 —— 小孩不干活，老人半个，饿的人没力气。
>
> 一个公式的改动（约 20 行），但它把村子从「人数 = 产能」变成「**结构 = 产能**」。
>
> 实测：40 种子 × 30 年 × 9 玩法，**灭村率 0%**。

---

## 1. 为什么

现在的产出公式（`AdvanceGranary`）：

```csharp
int num4 = population * 4 + val;      // 人口 × 4
```

**没有年龄项，没有饥饿项。**

于是：

| 现象 | 现在 | 应该是 |
|---|---|---|
| 80 岁老人 | 和壮劳力一样产 4 粮 | 半个 |
| 3 岁小孩 | 和壮劳力一样产 4 粮 | 不干活 |
| 饿到 98 的人 | 照样产 4 粮 | 没力气 |
| 童工(39) | 只加饥饿 | **让小孩也上工** |
| 弃老(40) | 只是处死老人 | **老人的产出是真成本** |
| 兵役(15) | 只影响出生 | 抽走青壮年 → 减产 |

**所以现在的「灾年」只是死亡倒计时，不是经济下滑。**
玩家看到的是「人一个个死」，不是「村子越来越穷」。

---

## 2. 改法

### 2.1 产出公式

```csharp
// ❌ 原来
int num4 = population * 4 + val;

// ✅ 改成
int num4 = LaborOutput(data) + val;
```

### 2.2 劳动力的折算

```csharp
/// <summary>全村劳动力折算成粮食产出。</summary>
private static int LaborOutput(VillageSaveData data)
{
    bool childLabor = HasLaw(data, 39);        // 童工：10 岁以下也能上工
    long work = 0;                             // 单位 = 百分之一全劳力

    for (int i = 0; i < data.villagerAlive.Length; i++)
    {
        if (!data.villagerAlive[i]) continue;

        int age = data.villagerAges[i];
        int pct;                               // 这个人的干活能力（百分比）
        if (age < 10)       pct = childLabor ? 50 : 0;
        else if (age < 16)  pct = 50;          // 半劳力
        else if (age >= 60) pct = 50;          // 老劳力
        else                pct = 100;         // 全劳力

        // 饥饿只扣一半：饿到 100 也还剩 50% 力气
        int lost = data.villagerHunger[i] / 2;
        int tired = pct * (100 - lost) / 100;

        // 兜底：饿到极限也还剩 10%，避免产出一夜归零
        int bottom = pct * 10 / 100;

        work += Math.Max(tired, bottom);
    }

    return (int)(work * 5 / 100);              // 每个全劳力产 5 粮
}
```

### 2.3 每人产出：定 **5** —— 要的是「饥荒咬人」

判定不能只看平均饥饿，要看四个**事件级**指标：

- 有多少局**真的经历过饥荒**（全村平均饥饿 ≥ 40 的月份）
- 每局饥荒持续几个月
- 每局**饿死多少人**（讣告里 cause = 饥饿）
- 灭村率（不能为了咬人把村子弄死）

**20 种子 × 30 年 × 9 玩法（饥饿强度 50%）：**

| 每人产出 | 末人口中位 | 平均饥饿 | 经历过饥荒的局 | 饥荒月数中位 | 饿死人数中位 | 灭村率 |
|---|---|---|---|---|---|---|
| 原版（人口即劳力） | 31 | 15 | 33% | 0 | 0 | 0% |
| 4 | 15 | 23 | 67% | 21 | 16 | **13%** ❌ |
| **5** | **25** | **17** | **58%** | **3** | **4** | **0%** ✅ |
| 6 | 27 | 13 | 40% | 0 | 0 | 0% |
| 7 | 30 | 9 | 22% | 0 | 0 | 0% |

**5 是「饥荒会咬人、但不会灭村」的边界。**

- **4**：灭村率 13% —— 太狠
- **5**：58% 的局碰到饥荒，中位饿死 4 人，**灭村 0%** ← 选这个
- **6 / 7**：饥荒几乎不发生（中位 0 个月）—— 村子平稳，但也不咬人

> **40 种子复核（5 × 50%）：**
> 末人口中位 25 · 平均饥饿 17 · **58% 的局经历饥荒** · 饥荒月数中位 3 ·
> **饿死人数中位 4** · 人口 IQR 18 · **灭村率 0%**。
> 作为对照，原版是 33% / 0 月 / 0 人 / IQR 29 / 0%。

### 2.4 为什么饥饿只扣一半

饥饿 100 时如果产出归零，饥荒会变成**自激振荡**（饿 → 零产出 → 更饿），村子会直接崩。

| 每人产出 · 饥饿强度 | 末人口 最小/中位/最大 | 平均饥饿 | 灭村率 |
|---|---|---|---|
| 6 · 100% | 0/21/127 | 15 | 13% ⚠ |
| 6 · 50% | 3/27/124 | 13 | 0% ✅ |
| 7 · 100% | 0/27/126 | 10 | 3% ✅ |
| **7 · 50%** | **3/30/126** | **9** | **0%** ✅ |
| 7 · 25% | 4/30/126 | 8 | 0% ✅ |

**选「每人 7 · 饥饿扣一半」。**

## 3. 实测：接上之后会怎样

**20 种子 × 30 年 × 9 玩法，原版 vs 劳动力（5 × 50%）：**

| 玩法 | 原版 末人口 | 平均饥饿 | **劳动力** 末人口 | 平均饥饿 | 灭村率 |
|---|---|---|---|---|---|
| 不装法 | 5/10/13 | 16 | **4/8/11** | 17 | 0% |
| 默认三法 | 28/39/63 | 18 | **19/26/35** | 23 | 0% |
| 开垦系 | 94/121/126 | 0 | **49/88/120** | 0 | 0% |
| 苛政 | 2/9/14 | 7 | **3/8/13** | 6 | 0% |
| 劳役系 | 23/25/25 | 16 | **9/24/25** | 16 | 0% |
| 兵役系 | 26/33/50 | 17 | **13/25/31** | 22 | 0% |
| 恐惧系 | 25/28/59 | 19 | **11/26/31** | 26 | 0% |
| 祭祀系 | 25/35/63 | 18 | **8/25/31** | 23 | 0% |
| 满槽6条 | 79/121/126 | 0 | **37/93/125** | 0 | 0% |

**三件事：**

1. **村子变小了，也变饿了。** 默认三法中位 39 → 26，平均饥饿 18 → 23。
   恐惧系 19 → 26 —— **恐惧和饥饿第一次同时在涨。**
2. **上限被砍掉一大截。** 开垦系 121 → 88，默认三法 63 → 35，祭祀系 63 → 31。
   **大村子养不起那么多不干活的人。**
3. **但一个村子都没被饿光。** 9 种玩法全部 **0% 灭村**。

**一句话：人口上限从「有多少人」变成了「有多少能干活的成年人」。**

> ⚠ 想让饥荒再狠一点，每人产出调到 4 —— 但灭村率会跳到 13%。
> **5 是边界。**

## 4. 和现有法条的联动

| 法条 | 现在 | 接上劳动力之后 |
|---|---|---|
| **童工 39** | 只加饥饿 | **10 岁以下也能上工（半劳力）** —— 第一次有真正的好处 |
| **弃老 40** | 只是处死老人 | 老人只产 50%，弃老省下的口粮和失去的产出**第一次可以比较** |
| **劳役 11** | 加产出、加饥饿 | 对比更清楚：逼人干活 vs 让人饿 |
| **兵役 15** | 只影响出生 | **（未接）** 应该抽走青壮年 → 直接减产 |
| **耕作 5 / 济贫 1** | 用人口算 | 仍然用人口 —— 见 §6 |

## 6. 两个已知的后续项

1. **耕作(5) 和劳役(11) 的加成仍然用 `population`。**
   它们会给「劳动力不足的村子」按人头发钱，部分抵消劳动力约束。
   建议后续改成 `work / 4` 和 `work / 5` —— 但要重扫一次，这次没做。

2. **兵役征召没有真的抽人。** 现在它只改出生率。
   接上「抽走青壮年」之后，劳动力才会真正痛 —— 那是下一轮的活。

## 7. 验收清单

- [ ] 装童工(39) 之后，村里的产出**明显上升**（小孩开始干活）
- [ ] 默认三法的末人口上限从 **63 降到 ~35**（大村子养不起闲人）
- [ ] 中位人口 **25 上下**（原版 31）—— 村子整体变小
- [ ] **一半以上的局经历过饥荒**（有月份全村平均饥饿 ≥ 40）
- [ ] 每局**中位饿死 3–5 人**
- [ ] 灭村率 ≈ 0
- [ ] 一个饥饿很高的村子，产出**确实**低于同人口的饱村子
- [ ] 同一种子跑两遍结果完全一致
