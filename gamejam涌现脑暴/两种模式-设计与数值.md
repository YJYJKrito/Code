# 两种模式 · 设计与数值


> ⚠ **部分数值已随 10.19 修复变化**：全局条件法不再 ×人口，流民法 / 共井的高压强度明显下降；20 种子回归见 [回归对比-10.19修复.md](回归对比-10.19修复.md)。机制定义仍可参考，最终以 [当前机制真实规格-修复版.md](当前机制真实规格-修复版.md) 为准。

> **模式 A：五十年**（固定时长）
> **模式 B：高压**（达到分数并维持 → 结算用时）
>
> 所有数字来自实测：新构建，10 种子 × 50 年 × 10 玩法。

---

## 0. 为什么 B 模式不能是「达到分数就停」

先看实测的实时分轨迹。定义：

```
V = 健康人口 × 2
健康人口 = Σ(100 − 饥饿)/100     （全村存活者）
```

| 玩法 | V 峰值 | V@第10年 | V@第30年 |
|---|---|---|---|
| 不装法 | 70 | 44 | 10 |
| 默认三法 | 72 | 38 | 26 |
| 满槽6条 | 74 | 50 | 38 |
| 流民法 | 92 | 52 | 70 |
| 苛政 | 0 | 0 | 0 |

**两个问题：**

1. **开局 V 就有约 40**（20 人、饥饿很低）。「达到 60」第 1 年就完成了 —— 模式会在 1 分钟内结束。
2. **村子是慢性下降的**：V@10 年只有 38–52，到 30 年掉到 10–26。

**所以「达到分数就结算」必须改成「达到并维持」。**
维持期正好利用了村庄的慢性下降 —— **压力来自「守住」，不是「冲高」。**

## 模式 A：五十年

### A.1 基本规则

| | |
|---|---|
| 时长 | **50 年**（`DaysBeforeYear(50) × 8` = 18263 天 = 146,104 tick） |
| 现实时间 | **16.5 分钟 @1x** · 8.2 分钟 @2x · 5.5 分钟 @3x |
| 结束 | 期满 / 绝户 / 名存实亡（连续 24 个月 < 5 人） |
| 评分 | 与 30 年相同，**但满分线 1200 → 2000** |

### A.2 评分

```csharp
int life    = clamp(personYears * 100 / 2000, 0, 100);
int welfare = clamp(100 - avgHunger * 2 - famineMonths / 2, 0, 100);
int total   = (life * 70 + welfare * 30) / 100;
```

> **为什么是 2000**：50 年实测人年 p50=880、p75=1185、p90=1480、max=2015。
> 1200 会让 p75 以上全部顶格。

### A.3 等级线（50 年实测分位）

实测总评（2000 满线，**退化 1%**）：p10=30 · p25=46 · p50=58 · p75=67 · p90=85 · max=98。

| 等级 | 总评 |
|---|---|
| **S** | ≥ 85 |
| **A** | ≥ 67 |
| **B** | ≥ 58 |
| **C** | ≥ 40 |
| **D** | < 40 |
| **F** | 未通关 |

> ⚠ **50 年比 30 年残酷得多**：实测整体灭村率 **36%**（30 年 16%）。

### A.4 ★ 50 年局的平衡调整（已实测）

**唯一需要改的一处：耕地退化 2% → 1%。**

| 配置 | 灭村率 | 人年中位 | 平均饥饿 |
|---|---|---|---|
| 现在（退化 2%） | **36%** | 816 | 22 |
| **退化 1%** | **15%** | **1123** | **13** |
| 退化 0% | 15% | 1326 | 3 |
| 5 → 6 粮/劳力 | 30% | 983 | 19 |
| 退化 1% + 6 粮/劳力 | 15% | 1226 | 9 |

**退化是 50 年局的唯一杀手** —— 粮仓产出随耕地退化而崩，饿死。
**只改退化率，其他都不动。**

```csharp
// 耕地退化
Rng.Chance(seed, tick, 31, i, 2)   →   Rng.Chance(seed, tick, 31, i, 1)
```

> 退化 0% 也能把灭村率压到 15%，但会让「开垦」和「耕作」失去张力 —— **选 1%**。

### A.5 实测：50 年各玩法（**调整后**，退化 1%）

| 玩法 | 人年 | 饥饿 | 饥荒月 | **总评(2000)** | 灭村 |
|---|---|---|---|---|---|
| 满槽6条 | 1863 | 14 | 0 | **85** | 0% |
| 流民法 | 1652 | 3 | 0 | **85** | 0% |
| 开垦系 | 1172 | 10 | 0 | **65** | 0% |
| 劳役系 | 1237 | 13 | 1 | **65** | 0% |
| 默认三法 | 1381 | 24 | 21 | **61** | 0% |
| 不装法 | 951 | 16 | 6 | **52** | 0% |
| 医耕 | 966 | 17 | 12 | **51** | 0% |
| 生育系 | 878 | 17 | 17 | **47** | 20% |
| 苛政 | 0 | 0 | 0 | **30** | **70%** |
| 恐惧系 | 0 | 0 | 0 | **30** | **60%** |

> **退化 1% 之后，正常玩法全部活下来**（默认 0% 灭村），只有苛政/恐惧系仍然崩。
> 这正是我们要的：**50 年不是"必然死"，而是"看你怎么治"。**

## 模式 B：高压

### B.1 核心：达到并维持

| 参数 | 值 | 说明 |
|---|---|---|
| 实时分 V | `健康人口 × 2` | 每月（240 tick）结算一次 |
| **目标线 T** | **45** | 必须连续维持 |
| **维持期 H** | **20 年** | 中途掉下目标线 → 连击清零 |
| **斩杀线 L** | **20** | V < 20 连续 **6 个月** → 直接失败 |
| 最长 | 50 年 | 还没达标 → 失败 |
| 平衡 | **退化 1%**（同模式 A） | 否则村子撑不到 20 年 |
| **结算** | 完成维持的那个月 → **用时** | 记录「第几年第几月」 |

```
V ≥ T 连续 H 个月  →  通关，用时 = 达标的月份
V < L 连续 6 个月  →  失败（罢黜）
```

### B.2 ★ 怎么把一局拉到 10 分钟以上（实测）

**单靠调 H 不够** —— 村子在 30 年后开始崩，任何「维持」都撑不过 25 年。
真正的杠杆是 **退化 1%**（同模式 A）：村子活得久，维持才可能久。

**退化 1% 下，T × H 的实测：**

| 目标线 T | 维持 H | 通关率 | **通关用时中位** | 失败用时中位 |
|---|---|---|---|---|
| 40 | 10 年 | 54% | 11 年 | 28 |
| 40 | 15 年 | 34% | 16 年 | 32 |
| 40 | 20 年 | 29% | **21 年（6.9 分钟）** | 32 |
| 45 | 10 年 | 20% | 21 年 | 34 |
| 45 | 15 年 | 17% | 25 年 | 35 |
| **45** | **20 年** | **13%** | **31 年（10.2 分钟）** | 35 |
| 50 | 15 年 | 14% | 26 年 | 35 |
| 50 | 20 年 | 12% | **33 年（10.9 分钟）** | 36 |

**选 T=45 · H=20 年**：
- 通关用时中位 **31 年 = 10.2 分钟 @1x**（3.4 分钟 @3x）
- 失败也会拖到 35 年左右 —— 高压模式本来就不该轻松

> 想更友好一点可以选 **T=40 / H=20**：通关率 29%、用时 21 年（6.9 分钟）。
> 但那就不到 10 分钟了。

### B.3 「用时」怎么记

不是「第几月第一次到 45」，而是**完成 20 年维持的那个月**。

```
第 1 年达标 → 第 3 年掉下去（连击清零）
第 5 年再达标 → 第 25 年完成 20 年维持 → 用时 = 25 年
```

**它衡量的是「稳定」，不是「爆发」。**

### B.4 斩杀线的意义

V < 20 连续 6 个月 → 失败。
实测苛政/恐惧系开局就死，会在 1–2 年内被斩杀 —— **不会让玩家拖着一个空村子点 50 年**。

### B.5 UI

```
┌──────────────────────────────────────┐
│  村力  47 / 目标 45   ✓ 已维持 12 年  │
│  ████████████████░░░░░  斩杀线 20     │
└──────────────────────────────────────┘
```

- 一条横条：**左端 0，右端 100**，目标线 50 画一条刻线，斩杀线 20 画一条红刻线
- 当前值用一个标记
- 维持进度：`已维持 12 年 3 个月 / 20 年`

### B.6 结算页

```
高压模式 · 通关
用时  第 31 年 4 月
最终村力 63 · 人口 41 · 讣告 187
最致命的法：济贫（131 人）
```

## 一、两种模式的对比

| | 模式 A 五十年 | 模式 B 高压 |
|---|---|---|
| 结束 | 50 年 / 灭绝 | 维持达标 / 斩杀 / 50 年上限 |
| 结果 | 评分 + 等级 + 称号 | **用时** |
| 玩家目标 | 撑满 50 年 | 把 V 稳在 45 以上 20 年 |
| 压力来源 | 慢性衰败 | **连击会被打断** |
| 时长 | 16.5 分钟 @1x | **约 31 年（10.2 分钟 @1x）** |
| 适合 | 想看完整个村史 | 想挑战/速通 |

## 二、实现清单

### 模式 A（在现有评分上改）

1. `RunYears = 50`
2. 评分满线 `1200 → 2000`
3. 等级线按 §A.3
4. 其余不变（人年、温饱、结局、称号）

### 模式 B（新增）

```csharp
public int mode;              // 0=五十年 1=高压
public int vStreak;           // 连续满足 V>=T 的月数
public int lowStreak;         // 连续 V<L 的月数
public int clearMonth;        // 通关月份（0=未通关）
```

每月（240 tick）：

```csharp
int v = HealthyPop(data) * 2;
vStreak  = (v >= TargetV) ? vStreak + 1 : 0;
lowStreak= (v <  KillV)   ? lowStreak + 1 : 0;
if (vStreak >= HoldMonths)      endingKind = EndingClear;  // 通关
else if (lowStreak >= 6)        endingKind = EndingDismissed;
```

`HealthyPop` 需要每 60 tick 刷新一次（O(人口)，可忽略）。

### 确定性

- 全部整数；V 是整数
- 连击按月判定，不依赖帧率

## 三、验收

- [ ] 50 年局在 146,104 tick 时结束
- [ ] 50 年评分不出现大面积顶格（p90 ≤ 90）
- [ ] 高压模式：正确局（默认/满槽/流民）能通关，苛政/恐惧在 2 年内被斩杀
- [ ] 连击在掉下目标线时**立刻清零**
- [ ] 「用时」记录的是完成维持的月份，不是首次达标的月份
- [ ] 同一种子跑两遍结果一致

---

## 四、一句话

> **模式 A 是「看完一届任期」，模式 B 是「守住一条线」。**
>
> **高压模式的分数不是越攒越多，而是随时可能掉下去 —— 这才是压力。**
