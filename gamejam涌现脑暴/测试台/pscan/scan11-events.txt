# 事件触发 · 第三轮：**条件换成权重**（20 种子 × 30 年）

规则：每 1800 tick 抽一次，**每个事件永远可抽**，权重随状态变。
**没有条件，就没有「永不触发」。**
权重恒 >= 1，所以每个事件在任何玩法下都至少有一点机会。

权重表：

| 事件 | 权重 |
|---|---|
| 蝗灾 | `1 + 平均饥饿/4` |
| 疫病 | `1 + 人口/15` |
| 边患 | `3`（定期，与状态无关）|
| 民变 | `1 + (300−威信)/12 + 平均恐惧/3` |
| 贪墨 | `1 + 税库/100` |
| 寒潮 | `3` |
| 匪患 | `1 + 金币<10人数/5` |
| 丰年 | `1 + max(0, 40−平均饥饿)/4` |
| 商队 | `1 + 税库/60` |
| 乡绅 | `1 + 威信/100` |
| 人口回流 | `1 + max(0, 50−人口)/10` |
| 名医 | `1 + 税库/80` |
| 大赦 | `1 + 威信/120 + 平均恐惧/3` |
| 新生儿潮 | `1 + max(0, 15−平均恐惧) + 粮仓/200` |
