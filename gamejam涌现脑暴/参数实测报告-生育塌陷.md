## 0. 一句话

```
这个游戏现在只有一种结局形态：
  第 1–3 年猛生一批 → 生育永久停止 → 人口一路衰减 → 第 19 年前后崩到 1 人 → 卡死

  34 条法条里，只有 6 条能改变这个结局。其余 27 条，装上去和不装一模一样。
```

---

## 1. ★★★ 根因：生育在第三年永久停止 ★★★

不装任何法，单种子逐年：

| 年 | 人口 | 育龄女 | 冷却 OK | **子女 < 6** | 真正可生 | 本年出生 |
|---|---|---|---|---|---|---|
| 1 | 49 | 8 | 4 | **8** | 4 | **+33** |
| 2 | 43 | 8 | 6 | **5** | 4 | **+9** |
| 3 | 37 | 7 | 6 | **0** | **0** | +4 |
| 4 | 28 | 7 | 7 | **0** | **0** | **0** |
| 5 | 24 | 7 | 7 | **0** | **0** | **0** |
| … | … | … | … | 0 | 0 | **0** |
| 19 | 2 | 1 | 1 | 0 | 0 | 0 |
| 20 | **1** | 1 | 1 | 0 | 0 | 0 |
| 21+ | **1** | 0 | 0 | 0 | 0 | 0 |

**拦住生育的不是年龄、不是冷却、也不是饥饿 —— 是 `villagerChildren < 6` 这个上限。**

```csharp
// CanGiveBirth
if (... && data.villagerBirthCooldown[index] <= 0
    && data.villagerChildren[index] < 6        // ★ 就是这个
    && data.villagerHunger[index] < 60 && data.villagerFear[index] < 70)
```

**8 位开局女性在 3 年内各自生满 6 个孩子，然后全村进入永久不育。**
第 3 年以后，即使村里还剩 7 个育龄女性、冷却全部就绪 —— **一个孩子也不会再生。**

而 `villagerChildren` **只增不减**，所以这个状态**不可逆**。

---

## 2. 于是整个游戏塌成了一句话

```
头 3 年，8 位女性生完全部配额  →  接下来 15 年是生育真空
                              →  第 19 年，头批孩子才成年
```

**这 15 年里，村子能不能活下来，只取决于一件事：头 3 年生的那批孩子能不能活到 18 岁。**

孩子死于饥饿 → 第 19 年没人成年 → **村子永远回不来**。

> **所以：能压住饥饿的法条 = 能救村的法条。其余法条对结局没有可测量的影响。**

这不是"平衡没调好"，是**生育模型本身是"一次性"的**。

## 3. 单条法扫描：33 条里只有 6 条有效

**30 年 × 120 种子，每条法单独安装。**

| 法条 | 末人口 中位 | 最小/最大 | 灭村率 | 末人口=1 | 有影响？ |
|---|---|---|---|---|---|
| **1 济贫** | **26** | 20/40 | 0% | 0% | ✅ |
| **13 公共卫生** | **26** | 20/41 | 0% | 0% | ✅ |
| **52 抚孤** | **26** | 20/39 | 0% | 0% | ✅ |
| **71 开垦** | **21** | 12/38 | 0% | 0% | ✅ |
| **59 多子** | **10** | 7/13 | 0% | 0% | ✅ |
| **51 常平** | **0** | 0/1 | **98%** | 2% | ✅（**反向**）|
| 54 减口 | 1 | 0/1 | 18% | 82% | 半有效（只会更糟）|
| **其余 27 条** | **1** | 1/1 | 0% | **100%** | ❌ **与"不装法"逐位相同** |

**27 条法（税收 / 耕作 / 医药 / 婚育补贴 / 幼童口粮 / 恐惧蔓延 / 连坐 / 买粮 / 平粜 …）装上去，和不装法跑出来一模一样。**

**为什么这几条有效**（看效果就明白了，全部是"压饥饿"）：

| 法条 | 效果 |
|---|---|
| 济贫 | 饥饿 > 45 → 从粮仓取粮（**绕过 40 预留线**）|
| 公共卫生 | 每 240 tick，**全员**饥饿 −2、恐惧 −1 |
| 抚孤 | 幼儿夭折 > 2 时，**全员**饥饿 −4、恐惧 −4 |
| 多子 | 子女 > 2 的人 饥饿 −6（抽粮仓）|
| 开垦 | 耕地不退化 → 产出维持（见 §5）|
| **常平** | **全员饥饿 +2**，所以它把村子饿死（98% 灭村）|

> **`LawScope.All` 的「全员饥饿 −2」是全局最强的效果**，因为它是无条件的、周期性的、对每个人生效的。
> 而 `+1 饥饿 / 32 tick` 是饥饿的自然增长 —— 一次 −2 抵掉 64 tick 的积累。

### 3.1 组合也救不回来

| 法条组 | 末人口 最小/中位/最大 | 灭村率 |
|---|---|---|
| 空置 | 1 / 1 / 1 | 0% |
| 默认（济贫 耕作 税收）| 19 / 26 / 43 | 0% |
| **生育系（婚育 幼童 医药）** | **1 / 1 / 1** | **0%** |
| 恐惧系（蔓延 私刑 连坐）| 0 / 1 / 1 | 1% |
| 苛政（减口 童工 税收）| 0 / 1 / 1 | 13% |
| 开垦（开垦 耕作 医药）| 23 / **56** / 81 | 0% |
| 单条济贫 | 20 / 26 / 40 | 0% |
| 满槽 6 条 | 26 / **49** / 81 | 0% |

**「婚育补贴 + 幼童口粮 + 医药」这套看起来最像"鼓励生育"的组合，末人口是 1。** 因为它一条饥饿都不压。

## 5. 其他确证的数值问题

**① 初始人口结构是写死的，和种子无关。**
```csharp
villagerAges[i]   = i switch { 19 => 78, 9 => 82, _ => 18 + (i*7+5) % 38 };
villagerGenders[i] = i % 2;
```
**每个种子的开局人口曲线完全一样。** 种子只影响名字、金币/饥饿/恐惧初值、词条和地图。所以 §1 那张表在 120 个种子上逐位相同。

**② 粮仓常年钉在 40，40 粮摆着没人吃。**
```
逐年粮仓：年1 178 → 年2 129 → 年3 72 → 年4 起长期 34–40
```
`GranaryReserve = 40` 的意思是"低于 40 就不再给村民发粮"。而收支恰好让它常年停在 40 —— **于是村民在旁边饿死，粮仓里躺着 40 粮。**

**③ 常平是一条"反向法条"。**
`E(Add, All, Hunger, +2)` —— 全员饥饿 +2。它是唯一一条会**主动饿死人**的常驻法，98% 灭村率就是这么来的。

**④ 恐惧不装法条就是死的。**
`恐惧 → 个人基准`（普通 12 / 怯懦 30 / 果决 5），第 7 年后就不再变化。不装恐惧系法条，恐惧全程在 7–23。

**⑤ 税库是死参数。** 27–48，全程不变。

## 7. 结论：现在该做什么

**不是游戏目标，不是新内容 —— 是修生育模型。**

理由：现在**没有任何"目标机制"可以建**。因为

1. 所有局的结局形态相同（崩到 1 人）
2. 33 条法里 27 条对结局无影响 → **玩家的选择没有后果**
3. 一局的形状完全由"孩子能不能活到 18 岁"决定，而这又几乎只由饥饿决定

**要先让"不同的法条组跑出不同的结局"，才谈得上目标、评分、斩杀线。**

### 具体要动的三个地方

| # | 问题 | 建议 |
|---|---|---|
| 1 | **`villagerChildren < 6` 让生育变成一次性** | 要么去掉这个上限，要么改成随时间/年龄变化的生育率，让生育是"持续的"而不是"生满就停" |
| 2 | **初始人口是一代人**（女性 18–40 岁，同一批） | 让初始年龄分布**跨越两代**，或者**跟种子相关**，这样一开局就有稳定的育龄人口 |
| 3 | **`GranaryReserve = 40` 把村民饿死** | 让预留线随人口缩放（比如 `人口 × 2`），而不是写死 40 |

> **这三条改完，"哪些法条有影响"这个问题的答案才会变。** 现在测出来的"27 条法无效"，很大程度是这三条造成的，不是法条设计得不好。
