## 2. 两种用法

### A. 先跑起来验证（最快）

1. 备份原始包体的 `立法村_Data/Managed/Assembly-CSharp.dll`。
2. 用本包的 `Assembly-CSharp.dll` 覆盖它。
3. 启动 `立法村.exe`。

这只适用于 **10.19 这个 Mono 构建**；DLL 与交付的 diff/源码已经核对一致（md5 `00e1bd72b987b314e46f303a839fc92d`）。
如果包体里其它 DLL/场景也换过，请以 Unity 工程源码为准，不要直接覆盖。

### B. 合入 Unity 工程（正式做法）

`修复补丁-10.19-反编译源码.diff` 是相对**反编译结果**的，不是相对工程源码；缩进/局部变量名可能不同。
请按 `修复补丁说明-给程序.md` 里的**类名 + 方法名**逐项合入，不要盲目 `git apply`。

优先顺序建议：

1. `LawEngine`：全局条件法、目标 guard、快照、强度/废止、`DisableStrongestLaw`
2. `VillageLifecycleService`：脚本法强度、移民、事件死亡计数、沙盒采样
3. `VillagerProfessions`：屠者判据
4. `RunRules`：健康人口公式
5. `VillageEvents`：事件文本点名 + 事件效果按 `LawPct` 缩放
6. UI：模式选择、主菜单空引用、HUD、法槽“已废止”
7. `LawCatalog`：卡面阈值/文案

- 制度疲劳（`hitsTotal` / 普惠法永久减半）仍未实现。
- 厚葬/香火/抚孤/夭殇/共井的“按死亡数/人口/邻居死亡”动态量仍是近似值。
- 慷慨/合群/孤僻三个词条无效果；守寡(16)、守丧(134217728) 烙记从不授予；`tyrantMode` 从不置 true。
- 高压模式在修复后强解集中到“满槽六法”（10/20 通关）；单条流民法/共井不再能通关。这是修 ×人口 后的真实平衡，需要另做一轮数值调参。

## 5. 复现回归

```bash
# 备份 测试台/pscan/Sim.cs
cp 测试台/pscan/Sim.cs 测试台/pscan/Sim.cs.orig
cp Sim.patched.cs.txt 测试台/pscan/Sim.cs

cd 测试台/pscan
dotnet run -c Release -- runmode 20     # 两种模式
dotnet run -c Release -- bugcheck 20    # 不变量
dotnet run -c Release -- obit 20        # 归因
```

基线请用原始 `Sim.cs.orig`（或 10.19 包体反编译源码）。
