# 《立法村》最低配置要求（Windows）

| 项目 | 最低配置 |
|---|---|
| **操作系统** | Windows 10 64 位 / Windows 11 64 位 |
| **处理器** | Intel Core i3-6100 或 AMD Ryzen 3 1200 及以上（双核 2.0 GHz 以上） |
| **内存** | 8 GB RAM |
| **显卡** | 支持 DirectX 11 的显卡，1 GB 显存（Intel HD Graphics 4000 / NVIDIA GeForce GTX 660 及以上） |
| **存储空间** | 1 GB 可用空间 |

**附注**

- 仅支持 64 位处理器和操作系统。
- 需要 DirectX 11 兼容显卡。
- 最低分辨率 1280×720，默认 1920×1080 全屏运行。
- 游戏为 2D 画面，核显即可流畅运行；上述显卡要求主要针对 DirectX 11 支持，而非性能门槛。

---

*依据：Unity 2022.3.62f3（64 位 Windows 构建），完整包体约 127 MB，单张地图烘焙贴图 3072×2048，1 个约 4 分钟的音频片段。*
