## 2. 一个 tick 的结算顺序

`VillageLifecycleService.SimulateTick` 的固定顺序：

1. 记录进入时的 tick、存活人数。
2. `LawEngine.BeginTick`：清空本 tick 的死亡标记。
3. **遍历每个存活村民**（数组顺序）：
   - `AdvanceAge`：年龄 tick +1；生日则年龄 +1；生育冷却 −1。
   - 饥饿 ≥99 → 饿死；恐惧 ≥99 → 吓死。
   - 否则若刚过生日且寿终判定命中 → 寿终。
   - 否则 `AdvanceNeeds`：饥饿、进食、恐惧、税收、劳役。
4. 每 56 tick：`AdvanceGranary`（产出、消耗、分粮）。
5. 每 120 tick：`ResolveInfantMortality`（幼儿夭折）。
6. 每 60 tick：`Traits.SurvivorScan` + `VillagerProfessions.Scan`（词条/职业）。
7. 每 240 tick：`ResolveBirths`（生育）。
8. 每 2400 tick：移民检查、税库进项/官吏俸禄。
9. `VillageEvents.Tick`：结算到期兆头，或抽新兆头。
10. 每 240 tick：`RunRules.Tick`（月度采样、结局判定）。
11. `Farmland.Tick`：每 120 tick 开垦，每 2400 tick 退化。
12. **`LawEngine.Tick`**：按法槽 1→6 结算法律。
13. 每 60 tick：威信结算。
14. `tick++`；若正式模式且 tick ≥146104 → 期满。

> **死亡计数**：法律击杀发生在第 12 步，晚于自然死亡。`LawEngine.Tick` 内部会把前面法条造成的死亡累加到 `deathsSeen`，所以**后面的法条**能看到本 tick 前面法条杀的人。条件本身仍是逐村民实时判定；只有 guard 读触发前快照，同一法可能因前面的效果让后面的村民新满足条件。

## 3. 法律引擎

### 3.1 触发粒度（修复后）

- **自身/邻居类条件**（`SelfGt/SelfLt/SelfEq/NeighborGt/NeighborRelative/NeighborDiedThisTick`）：逐村民触发，每个满足条件的人各执行一次。
- **全局条件**：只要所有条件都是全局量（人口、计数、资源、周期、累计、已装法、`OnDeath` 等），整条法**每 tick 只触发一次**，触发者取第一个存活村民。
  - `SelfGt/SelfLt/SelfEq` 如果读的是 `粮仓/税库/威信/累计死亡/累计出生/幼儿夭折/讣告数`，也按全局条件处理。
- **共享资源**（粮仓/税库/威信）的 `Add` 每 tick 只结算一次（`firstTrigger` 去重）；`SetField` 幂等；`Move/FillTo` 不去重。
- **目标筛选**：`All` / `Neighbors` 作用域的 guard 判定**目标**；`Self` 与共享作用域判定**触发者**。
- **快照 guard**：每条法触发时先快照一次村民/资源状态；同一条法的多个效果都读这份快照，不会出现“先 −20 再 +2”或“先扣税库再判定税库”的连锁误判。

### 3.2 条件与效果

**21 种条件**：

| 类别 | 条件 |
|---|---|
| 自身 | `SelfGt / SelfLt / SelfEq`（字段、阈值） |
| 邻居 | `NeighborGt`（任一邻居字段 > a）、`NeighborRelative`（邻居字段 > 自己 + a）、`NeighborDiedThisTick` |
| 村庄 | `AliveGt / AliveLt`、`CountGt / CountLt`（超过/少于 b 人满足字段阈值）、`AvgGt` |
| 资源 | `ResGt / ResLt`、`ResLtPopTimes`（资源 < 人口 × a） |
| 时间 | `Periodic`（tick % a == 0）、`DeathsThisTick` |
| 历史 | `TotalGt`（累计死亡/出生/夭折/讣告）、`ObituaryCountGt` |
| 其他 | `HasLaw`、`Always`、`OnDeath` |

**13+2 种效果**：

| 效果 | 说明 |
|---|---|
| `Add` | 加/减字段；正恐惧会经过坚韧/脆弱修正 |
| `SetField` | 设为固定值 |
| `Move` | 从邻居/公仓/税库转移给自己 |
| `Drain` | 从自己抽到邻居/公仓/税库 |
| `Steal` | 从左右邻居偷，合计不超过 amount |
| `FillTo` | 补到上限（`extra` 为上限） |
| `ModifyBirthCd` | 改生育冷却 |
| `KillSelf / KillMaxOf / KillYoungest` | 处决自己/字段最高者/最幼者 |
| `ModifyLawStrength` | `field` 字节被当作**目标 lawId**，改其强度 |
| `DisableLaw` | 把目标法强度置 −100 |
| `BoostOtherLaws` | 其他所有活跃法强度 +amount（威权 48） |
| `DisableStrongestLaw` | 废止强度最高的其他活跃法（全 0 时取第一个；无候选不生效）（赦令 49） |
| `BroadcastFrom` | 对全体广播 |

### 3.3 强度、冷却、guard

- `lawStrength` 范围 **−100..+100**；效果量 `amount × (100 + strength) / 100`（整数截断，正数至少 1）。
- 强度 ≤−100 = **废止**：`IsLawActive` 为 false，脚本法/DSL 法都不再生效；后续 `ModifyLawStrength` 的正面修改**不能复活**它，换成不同法时会把强度重置为 0。
- 冷却按 tick 计；触发后整条法进入冷却。
- guard：`guardField == 255` 表示无 guard；`guardOp == 0` 是 `>=`，否则是 `<`。
- 概率：每条效果独立 `chance`（默认 100%）。

### 3.4 立法、解锁、购买

- 6 个法槽；同一法不能重复装。
- 每次选择/替换 **−30 威信**；替换时新法的强度和冷却**重置为 0**。
- 隐藏法按解锁条件出现（累计死亡/出生、人口、粮仓、税库、幼儿夭折、恐惧>80 人数、金币<10 人数）。
- 稀有法（王权税契 24、雇佣护卫 25）用**税库金币**购买一次，之后永久可选。
- 已装法可以在任意时刻替换；换成不同法时强度/冷却重置，替换不会退还旧法的成本。重选当前法直接返回，不扣费、不重置。

## 4. 村民、生老病死

| 字段 | 范围/规则 |
|---|---|
| 饥饿 | 0–99；≥99 死亡 |
| 恐惧 | 0–99；≥99 死亡；正恐惧受坚韧/脆弱修正 |
| 金币 | 0–99；饥饿 >30 时可用 1 金换 4 饥饿 |
| 私粮 | 0–40；先吃自家，吃完才吃公仓 |
| 子女 | 累计生过几个（只加不减） |
| 在世子女 | 父母死亡时 −1 |
| 生育冷却 | tick 计数 |
| 先天词条 | 8 个轴，出生 1–2 个，可遗传 |
| 烙记/职业 | 13 个永久职业 + 状态 |

### 4.1 死亡

- **饿死**：饥饿 ≥99。
- **吓死**：恐惧 ≥99。
- **寿终**：60 岁起，每年生日掷骰；概率 `min(20, (年龄−60)² / 35) %`（即 `(年龄−60)²×100/3500` 个百分点）；劳损 +7 岁，医药 −5，病弱 ×1.15，强健 ×0.85。
- **夭折**：每 120 tick（15 天）对每个 <3 岁幼儿掷一次；基础 2% + 饥饿/恐惧/私粮/粮仓修正 + 法条/词条，钳位 1–30%。
- **律法/天灾**：由法条或事件直接调用 `KillByLaw`。

### 4.2 出生

- 每 240 tick；女性 18–42、非难育、冷却 0、子女 <12、饥饿 <60、恐惧 <70、私粮 ≥2 或公仓 ≥6。
- 基础概率 40%；婚育补贴 +35（粮仓>180 时置 100）、宵禁 −15、粮仓 >150 +12、粮仓 <70 −25、新生儿潮倍率、多产 +20、绝粮 −20。
- 成功：公仓 −12；母亲冷却 480（多产 240），父亲 360。
- 配对：第一个存活的 18–55 岁男性，且饥饿 <75、恐惧 <80；不看关系、不看年龄差。

### 4.3 年龄/移民

- 每 2400 tick，人口 <25 且粮仓 >20：**基础 +2 人**；装「流民法(17)」时 **+3 人**（并额外每 240 tick 全体饥饿 −4）。
- 事件「人口回流」另加 4 人（有徙民 6 人；装流民法 ×1.5 → 6/9 人）。

## 5. 经济

### 5.1 粮食

每 56 tick：

```
劳动力 = Σ 年龄权重 × max(100 − 饥饿/2, 10) / 100
  <10 岁 0（童工 39：50），10–16 半，16–60 满，60+ 半
产出 = 劳动力 × 5 / 100
      + 勤勉/懒散（每人 ±2，受人口/3 限制）
      + 耕作(5)：人口/4 × 强度
      + 劳役(11)：人口/5 × 强度
      × 耕地系数（1000 + (当前耕地−开局耕地)×1000/开局耕地×1400/1000，钳位 250–1600‰）
消耗 = 人口/3 + 济贫(1)：人口/8 × 强度
粮仓 += 产出 − 消耗
```

- 粮仓上限 **500**；低于 40 不再向村民分粮（保种子）。
- 粮仓 >40 时向私粮补：成人补到 20、幼儿补到 10。
- **开垦(71)**：每 120 tick，粮仓 <150 时花 15 粮 +2 金（荒地 30 粮 +4 金）把临接耕地的草地/荒地变耕地；上限为开局耕地 ×3。
- **退化**：每 2400 tick，每块耕地 **1%**（正式模式）/ **2%**（沙盒）概率退化，其中 35% 变荒地。

### 5.2 税库

- 每 2400 tick：`+⌊人口/3⌋ − ⌊人口/4⌋`（官吏俸禄），约 **+人口/12**（两次整除，个位数可能差 1）。
- 税收(3)：每 240 tick，金币 >60 的村民交 12 金；税库 +3、粮仓 +3（强度缩放）。
- 其他进项：买粮(26)、捐纳(28)、丁税(27)；出口：平粜(29)、常平(51)、开垦、稀有法购买、事件。

### 5.3 威信

每 60 tick：

```
回复 = 人口/4 + (12 − 平均恐惧)/2
若威信 >200：回复 × (300 − 威信) / 100
威信 = 威信 − 4 × 已装法条数 + 回复
```

- 0 → **停摆**：所有法失效（`prestigeSuspended`）。
- 停摆期间只回复；回到 **40** 恢复。
- 立法/换法 −30。

## 8. 死亡归因与讣告

每次死亡按顺序问：

1. **致死法**：装了某条“会加重这个死因”的法 → 「是你写的『X』。」
2. **缺位法**：没有致死法，但有一条“本可以救他”的法没装 → 「村里没有『X』。」
3. **无**：都没有 → 「没有一条法能替他负责。」

- 死因：饥饿、惊吓、夭折、寿终、律法、天灾。
- 天灾死亡单独走 `AttributeEvent`，每类有首选/备选两条：疫病→医药/公共卫生，边患→兵役征召/雇佣护卫，民变→安抚/济贫，匪患→宵禁/雇佣护卫。
- 讣告快照保存：年龄、性别、先天、职业、法名、归因种类。
- 结算页「最致命的法」只统计 `kind == 1`（致死），不再把“没装的法”算进去。

## 9. 结局与评分

### 9.1 五十年模式（runMode = 0）

- 每月采样：`personMonths += 人口`、`hungerSum += 平均饥饿`、`famineMonths += (平均饥饿 ≥40)`。
- 结束：
  - 人口 **≤2** → 绝户（endKind 2）
  - 人口 <5 连续 **12 个月** → 名存实亡（endKind 5）
  - tick ≥ **146,104** → 期满（endKind 4；修复后逐 tick 检查，正好 146,104）
  - 玩家手动结算 → endKind 4
- 评分：

```
存续 = clamp(personMonths × 100 / 24000, 0, 100)
温饱 = clamp(100 − 平均饥饿×2 − 饥荒月/2, 0, 100)
总评 = (存续×70 + 温饱×30) / 100
```

- 等级：S ≥85、A ≥67、B ≥58、C ≥40、D <40；失败 F。

### 9.2 高压模式（runMode = 1）

- 每月：`V = 2 × Σ(100 − 饥饿) / 100`（存活者；修复后为连续加权，不再用“饥饿<50 的人数”）。
- `V ≥ 45` 连续 **240 个月（20 年）** → 通关，记录完成维持的月份。
- `V < 20` 连续 **6 个月** → 罢黜。
- 50 年仍未达标 → endKind 4（期满）；结算标题当前显示为「高压模式 · 罢黜」，“用时”只在通关（endKind 1）时显示。
- 结算页显示：最终村力、用时、人口、讣告、最致命的法。

### 9.3 沙盒（runMode = −1）

- 不按 50 年到期；**人口归零会在下一次月度结算时判绝户并结束**。
- 玩家可随时点「结算」；人年/温饱采样对沙盒也累计，结算面板显示等级/总评/人年/人口/讣告/最致命法。
