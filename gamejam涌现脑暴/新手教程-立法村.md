# 《立法村》新手教程

> 适用版本：10.20 包体
> 阅读时间：约 10 分钟
> 一句话：**你不控制村民，你只写法律。然后看着他们按你写的法活下去，或者死掉。**

---

## 0. 先记住三件事

1. **你点不了村民。** 不能叫谁去种地，不能叫谁别抢，也不能给谁发粮。
2. **你能做的只有写法律。** 六条法槽，贴上去，它就会自动执行。
3. **每条法都会杀人，也会救人。** 讣告会告诉你，这次是谁的责任。

---

## 1. 开局：先选一个模式

进入新游戏后，游戏会暂停，屏幕提示：

```
按 1 = 五十年
按 2 = 高压
按 3 = 沙盒
```

| 模式 | 适合谁 | 结束条件 |
|---|---|---|
| **五十年** | 第一次玩，想看完整村史 | 活满 50 年；人口 ≤2 绝户；人口 <5 连续 12 个月名存实亡 |
| **高压** | 想挑战、想速通 | 村力 ≥45 连续 20 年通关；村力 <20 连续 6 个月罢黜 |
| **沙盒** | 想随便试试、不想被结局打断 | 无 50 年期限；人口归零会结束；可随时手动结算 |

第一次玩建议选 **五十年**。移动端会自动选五十年。

## 2. 界面速览

```
┌──────────────────────────────────────────────┐
│ 威信 100   本刻 -8   1x 2x 3x   0年1月  讣告 0 │  ← 顶栏
├──────────────────────────────────────────────┤
│                                              │
│                 村 庄 地 图                   │  ← 双击收起/放出上下栅

│ 第4条 空     第5条 空     第6条 空             │
└──────────────────────────────────────────────┘
```

- **顶栏**：威信、本刻增减、速度、年月、讣告数、模式状态。
- **地图**：看村民、房子、农田、水；双击地图可以收起/放出上下栅。
- **法槽**：你唯一能操作的地方。点一条法槽 → 打开法律选择。
- **村民面板**：点地图上的小人，看他的金币/饥饿/恐惧/存粮/子女/先天/职业。
- **讣告**：点顶栏的讣告数，看历史；有人死时会弹横幅。
- **菜单**：Esc 打开暂停菜单（存档、设置、回主菜单）。

## 3. 第一局怎么玩：看 → 读 → 换

### 第一步：先别急着改法

开局已经装好三条法：

> **济贫(1)**：饿的人可以从公共粮仓取粮
> **耕作(5)**：所有劳动力提高粮仓产出
> **税收(3)**：有钱人交税，税库和粮仓得到进项

先按 1x 速度看 1–2 分钟，观察：

- 粮仓是在涨还是在掉？
- 有没有人饥饿接近 99？
- 有没有人恐惧接近 99？
- 顶栏「本刻」是正还是负？

### 第二步：读第一条讣告

有人死时，屏幕上会弹：

```
讣告 · 沈石，47 岁。死于3年5月，饥饿。
是你写的『济贫』。
```

讣告的最后一句话分三种：

| 写法 | 含义 |
|---|---|
| 「是你写的『X』。」 | 你装的某条法加重了这个死因 |
| 「村里没有『X』。」 | 你本可以装某条法救他，但没装 |
| 「没有一条法能替他负责。」 | 没有直接责任法 |

**这就是游戏的核心反馈。** 不要只看数字，先看讣告在指控哪条法。

### 第三步：换一条法

点法槽 → 选新法。注意：

- 每次选择/替换 **−30 威信**；
- 同一法不能装两个槽；
- 换成不同法时，新法的强度和冷却重置；
- 装错了可以再换，但威信是有限的。

**不要每 10 秒换一次。** 先观察，再决定。

## 4. 法条怎么读

每条法就三部分：

```
条件：什么情况下触发
效果：触发了会怎样
槽位：第 1 条先结算，第 6 条最后结算
```

例子：

> **饥则抢**
> 条件：饥饿 > 55
> 效果：抢邻居 12 金币；自己恐惧 +3

意思是：**每个饥饿超过 55 的村民，都会去抢左右邻居的钱。**

### 两种触发方式

- **个人条件**：写的是「饥饿 > X」「恐惧 > X」「年龄 < X」——每个满足的人各触发一次。
- **全村/资源条件**：写的是「人口 > X」「粮仓 > X」「每 240 tick」「累计死亡 > X」——整条法每 tick 只结算一次。

### 法条也会变强/变弱

- 有些法会改另一条法的**强度**（比如峻法、苛敛、威权）；
- 强度 −100 = **废止**，这条法不再生效，法槽会显示「已废止」；
- 废止的法不再扣维持费，但仍占一个槽；换掉它才能腾出槽位。

## 5. 三个资源，三种死法

### 粮仓（最直接）

- 开局 220 / 上限 500；
- 产出看劳动力、耕作、劳役、耕地；
- 消耗看人口、济贫；
- **低于 40 就不再给村民分粮**；
- 粮仓见底 → 饥饿上升 → 饿死。

### 税库（买稀有法、救灾）

- 主要来源：税收法、人口周期进项、买粮/捐纳/丁税；
- 用途：买稀有法（王权税契 60、雇佣护卫 40）、平粜/常平换粮；
- 税库不是分数，是**防灾预算**。

### 威信（你的执政资本）

- 开局 100；
- 立法/换法 −30；
- 每条活跃法每 60 tick 扣 4；
- 回复看人口和平均恐惧；
- **归零 = 全局停摆**：所有法暂停，直到回到 40。

> 新手最常见的死法：法装太多 → 威信归零 → 所有法停摆 → 粮仓崩 → 饿死。

## 6. 村民身上有什么

| 属性 | 说明 |
|---|---|
| 饥饿 | 0–99，≥99 死 |
| 恐惧 | 0–99，≥99 死；会传染 |
| 金币 | 0–99；饿的时候可以买粮 |
| 私粮 | 0–40；先吃自家，吃完才吃公仓 |
| 子女 | 生过几个；影响继承/绝户/职业 |
| 先天词条 | 出生 1–2 个，影响饥饿、恐惧、生育、产粮 |
| 职业/烙记 | 由你装的法和村民经历长出来，永久保留 |

**先天词条**有 8 个轴：怯懦/果决、贪婪/慷慨、勤勉/懒散、病弱/强健、多产/难育、节俭/挥霍、合群/孤僻、坚韧/脆弱。不是每个词条都有效果，但目前大部分会改变行为。

**职业**有 13 个：罪人、劫匪、逃兵、劳损、债户、巫祝、恩主、屠者、绝户、光棍、积怨、尸亲、徙民。它们会影响事件结果，也会出现在村民面板和讣告里。

## 7. 事件：先看兆头，再决定改不改法

每局大约会发生十几次事件。每个事件分两段：

```
第 N 年：田里的蚂蚱比往年多。      ← 只有文本，没有效果
第 N+1 年：蝗群落下，半年的粮没了。 ← 这时才结算
```

中间有一年时间给你改法。比如：

- 看到「蚂蚱多」→ 装上 **耕作/开垦**，蝗灾损失减半；
- 看到「村口有人咳」→ 装上 **医药/公共卫生**；
- 看到「边境消息」→ 装上 **兵役征召**，边患可以不死人；
- 看到「有人夜里聚众」→ 装上 **安抚/济贫**，或别装 **连坐**。

**兆头期是这游戏唯一真正的新动词。** 不要忽略它。

14 个事件：蝗灾、疫病、边患、民变、贪墨、寒潮、匪患、丰年、商队、乡绅、人口回流、名医、大赦、新生儿潮。灾难和好事都有。

## 8. 两种模式的目标

### 五十年

- 活满 50 年；
- 结算看三件事：**人年、平均饥饿、饥荒月**；
- 等级 S/A/B/C/D，失败 F；
- 人年 = 这些年村里一共活过多少人·年。

### 高压

- **村力 = 2 × Σ(100 − 饥饿) / 100**；
- 村力 ≥45 连续 20 年 → 通关，记录用时；
- 村力 <20 连续 6 个月 → 罢黜；
- 压力不在“冲高”，在“守住”。

### 沙盒

- 没有 50 年期限；
- 人口归零会结束；
- 可以随时点「结算」，看当前的人年/温饱评分。

## 9. 新手三条原则

### 原则一：先保住粮仓，再谈理想

新手最容易犯的错：一口气装上「济贫 + 婚育补贴 + 幼童口粮 + 医药」四条善法，结果粮仓被吃空。

- 济贫会增加公共消耗；
- 婚育补贴会生更多孩子；
- 幼童口粮/医药会降低夭折，但孩子也要吃饭。

**善法不是免费的。** 先看粮仓产出，再决定加不加。

### 原则二：不要装满六条

六条法每 60 tick 扣 24 威信。威信一归零，全部停摆。

- 默认三法是稳的；
- 第 4–6 条只在需要时加；
- 换法要花 30，想清楚再换。

### 原则三：跟着讣告和兆头走

- 讣告说「是你写的『劳役』」→ 考虑降劳役或补粮；
- 讣告说「村里没有『医药』」→ 考虑装医药；
- 兆头出现 → 提前一年改法。

**不要盯着数字猜。** 讣告和兆头就是游戏给你的两条线索。

## 10. 推荐开局（第一局）

开局三条默认法不用动：

> 济贫(1) + 耕作(5) + 税收(3)

观察 1–2 分钟后，按情况加：

| 情况 | 加什么 |
|---|---|
| 粮仓长期低于 100，饥饿上升 | **开垦(71)** 或 **屯粮(30)** |
| 幼儿夭折多 | **幼童口粮(9)** / **医药(12)** |
| 恐惧普遍 >40 | **安抚(6)** / **宵禁(10)** |
| 税库长期 >100，想买稀有法 | **平粜(29)** / **常平(51)** |
| 人口掉到 20 以下 | **流民法(17)**（移民 +3/2400 tick） |

**第一局目标**：活满 50 年，拿到 B 以上，读至少 10 篇讣告。

## 11. 常见问题

**Q：为什么我点村民没反应？**
A：村民不能指挥。点开只是看状态。你唯一能操作的是法槽。

**Q：为什么我的法不触发？**
A：先看条件。比如「饥则抢」要饥饿 >55；如果村里没人饿到 55，它就不会触发。把鼠标/手指放到法条上看条件。

**Q：为什么全村突然死了？**
A：常见原因：粮仓见底、恐惧雪崩、威信停摆后法全失效、或者你装了一条会持续加饥饿/恐惧的法（立威、阴气、哭丧等）。看讣告和顶栏状态。

**Q：威信为什么掉这么快？**
A：每条活跃法每 60 tick 扣 4；换法再扣 30。法越多掉越快。归零会停摆。

**Q：法槽显示「已废止」是什么意思？**
A：被赦令(49)或其他法改法效果废掉了，当前不生效。换掉它才能腾出槽位。

**Q：为什么我选不了模式？**
A：新局会暂停等你按 1/2/3；如果提示 UI 丢失，10 秒后会自动进入沙盒。移动端默认五十年。

**Q：怎么暂停/加速？**
A：空格暂停观察；顶栏 1x/2x/3x 切速度；Esc 打开菜单。

**Q：为什么我活了 50 年还是 D？**
A：五十年看的是人年和温饱，不是“没死光”。人年少、平均饥饿高、饥荒月多，分数就低。

## 13. 术语表

| 词 | 意思 |
|---|---|
| **tick** | 最小时间单位；8 tick = 1 天，148 tick/秒 |
| **法槽** | 放法律的位置，共 6 条，按 1→6 顺序结算 |
| **条件** | 什么情况下触发 |
| **效果** | 触发后发生什么 |
| **强度** | 法条效果倍率；−100 = 废止 |
| **威信** | 立法/维持的资本；归零停摆 |
| **粮仓** | 公共粮食；低于 40 不再分粮 |
| **税库** | 买稀有法/救灾的钱 |
| **兆头** | 事件爆发前一年的文本预警 |
| **讣告** | 死亡时自动生成的小传，写明责任法 |
| **人年** | 每月人口累加 / 12，五十年评分主项 |
| **村力** | 高压模式的实时分：2 × Σ(100−饥饿)/100 |
