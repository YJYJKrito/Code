# 日志 07 · 10.19

### 《村子有了两种活法，讣告终于不再冤枉好人》

上一篇最后我说：修掉钳位，重调粮食，然后放第一篇**真实跑出来的讣告**。

这一篇把三件事都做了。而且放出来的讣告，让我发现它一直在冤枉人。

## 讣告在给善法定罪

先看一条。这是一局里真实生成的：

```
王麦，0 岁。
死于1年3月。还没满三岁。
是你写的『幼童口粮』。
```

**幼童口粮，是一条给小孩优先发粮的善法。**

问题出在归因函数上。它只问一件事：**这条法装没装。**

```csharp
// 旧代码
他死于夭折 → 查「幼童口粮」装了吗 → 装了，记它
```

于是只要你在法槽里放了幼童口粮，**每一个死掉的孩子都会被写成"死于幼童口粮"**。

它不报错，不崩溃，只是安静地把每一条善法变成凶手。

## 新规则：三种归因

现在每次死亡，按顺序问三个问题：

```
① 有没有一条「会加重这个死因」的法？   → 致死法
② 有没有一条「本可以救他」的法没装？   → 缺位法
③ 都没有                              → 无
```

三种写出来的句子完全不同：

| 归因 | 讣告里写 |
|---|---|
| 致死法 | 「是你写的『劳役』。」 |
| 缺位法 | 「村里没有『幼童口粮』。」 |
| 无 | 「没有一条法能替他负责。」 |

**「是你写的」是指控，「村里没有」是遗憾。**
两者都算因果，但玩家读到的重量不一样。

跑了 **13,452 篇讣告**做对照：**保护性法律被当成死因的次数是 0。**

现在讣告会告诉你两件事：

- **你装了劳役** → 3,721 个人因它而死
- **你没装幼童口粮** → 3,475 个孩子没能活过三岁

这两句，比我写任何一句总结都更像这个游戏。

## 一局有了终点：两种活法

之前没有结局。你写法律，村民生死，然后一直这样下去。

现在有两条路。

### 第一条：五十年

**一局五十年，约 16.5 分钟（1x）。** 活到期满就通关。
如果全村死光，或者**连续两年人口不足 5 人**，提前结束。

结算不是单一分数，是三个数：

```
人年    1424     ← 这五十年里，村里一共活过多少人·年
平均饥饿 24
饥荒     21 个月
```

再给一个等级（S/A/B/C/D）和一句谥号：仁政、威权、大兴、守成、苟存。

**为什么用人年，不用年末人口**：一个前 29 年 40 人、最后一年团灭的村子，和一个一直 10 人的村子，年末人口可能一样。**人年记录的是整条曲线。**

### 第二条：高压

这一条是给想挑战的人。

```
村力 = 健康人口 × 2
村力 ≥ 45 连续维持 20 年   → 通关，记录用时
村力 < 20 连续 6 个月       → 罢黜，直接结束
```

**压力不在"冲高"，在"守住"。** 村子会慢慢衰败，你的村力会往下掉——
掉到 20 以下六个月，这一局就结束了。

实测（每档 90 局）：

| 结果 | 局数 |
|---|---|
| 通关 | 16 |
| 罢黜 | 32 |
| 绝户 | 12 |
| 五十年没撑到目标 | 30 |

**通关用时中位：29 年，约 9.5 分钟。**

## 为了让五十年活得下去，我只改了一个数

第一版五十年的测试很难看：**36% 的村子在五十年里死光。**

查下来不是生育，不是税收——**是耕地退化。** 一块地种久了会退化，五十年足够让大半耕地废掉，粮仓跟着崩，然后饿死。

我把退化率从 **2% 调到 1%**：

| 退化率 | 灭村率 | 人年中位 | 平均饥饿 |
|---|---|---|---|
| 2% | **36%** | 816 | 22 |
| **1%** | **15%** | **1123** | **13** |

**一个数字，救回了 21% 的村子。**

而且我只在两种模式里改——沙盒模式仍然是 2%。

## 事件、律法、职业

这一版把之前设计的事件系统全接上了：

**14 个事件**，每局约 **22 次**。灾难和好事都有：蝗灾、疫病、寒潮、边患、民变，也有丰年、商队、名医、新生儿潮。

**每个事件都先给兆头，再过一年爆发。**

```
第 N 年    田里的蚂蚱比往年多。        ← 只有文本，没有效果
第 N+1 年  蝗群落下。                  ← 这时候才结算
```

玩家在这中间**可以改法**。这是整个设计里唯一真正新的东西——
它把「我三十年前写的一条法」变成了「**我现在要不要改**」。

**律法能改写事件。** 装了耕作，蝗灾的粮仓损失减半；装了兵役征召，边患一个人都不死。
反过来也成立：装了连坐，民变的伤害 ×1.5。

**职业有 13 个**，全部从「你写的法律」里长出来：装了私刑，村里出现罪人；装了祭祀，出现巫祝；处决过人，出现屠者。村里有医师，疫病就死得少。

## 美术：地图翻了一倍

上一版地图是 48×32 格、1536 块地。
这一版是 **96×64 格、6144 块地**——面积是上一版的四倍。

地块是 32×32 的像素图，按高程、湿度、温度长出来：水、沙漠、草原、荒地、雪。
每一格仍然要烘进一张大贴图，运行时仍然是一个 draw call，但这次地图真的有了"远处"。

**那张烘焙图现在是 3072×2048。** 包体里一共 **81 张纹理、65 个精灵**——
地图、法条卡、UI、人物都在里面。

【补一句美术同学的进度：这版画了哪些东西、画了多久、最满意的是哪一块】

界面也换了一版：标题木牌、九张法条卡（每张有自己的类别颜色和插图）、人物立绘和像素小人。
**法条卡下半部是空的**——那是留给玩家读条文的地方，不是装饰。

## 音乐：进来了

这一版接上了第一首背景音乐，叫 **《旷野悬声》**。

- **全长 3 分 59 秒**，48 kHz 立体声
- 循环播放，切场景不会断
- 跟随设置里的音量滑杆
- 没有音效——**一首循环曲 + 一个总音量**，这是刻意的减法

一局五十年约 16.5 分钟，**这首曲子会完整循环四遍**。

它只有一个要求：**不能抢走读字的注意力。**
所以没有鼓、没有人声、没有明显的旋律。你平时不会注意到它，
等村子空掉之后，你会记得它一直在。

## 收工前，我又抓到一个"不会报错"的 bug

结算页会显示「最致命的法」。我拿它跑了一圈：

```
最致命的法『幼童口粮』（3475 人）
```

**可那一局玩的是济贫·耕作·税收，从来没装过幼童口粮。**

原因和开头那个一模一样：讣告里现在存着两种法名——**致死法**和**缺位法**。
结算页只看了法名，没看它是哪一种，于是把「村里没有幼童口粮」也算成了「幼童口粮杀人」。

**60 局里，有 30 局的"最致命"是一个没装过的法。**

这是这一类 bug 的第 N 次：**不报错、不崩溃、只是安静地让游戏变得不对。**

> 我一度还怀疑"天灾"的讣告也在乱归因，去翻了代码——
> 结果发现那是有意为之：疫病找医药，民变找安抚。
> **这次是我把对的当成了错的。**
