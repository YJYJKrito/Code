---

## 0. 一句话

我们要一首**能听 20 分钟不烦**的中国乡村氛围音乐，
它**不是主角** —— 主角是屏幕上不断滚动的讣告。

**不需要好听，需要不碍事、且对劲。**

---

## 1. 这个游戏是什么（读完能理解语境）

你是一个村子的立法者。**你不能控制村民**，只能往法槽里放法律。
村民会因为这些法律活着或死掉，系统自动生成讣告。

> 游戏的口号是：**「他们死于你写的法律。」**

玩家做的事只有三件：

1. **看法条**，决定装哪几条；
2. **看村子**，看人在动、在饿、在死；
3. **读讣告**，知道刚才那条法杀死了谁。

一局 30 年，现实时间约 **10 分钟**。节奏很慢，大部分时间玩家在看，不操作。

**情绪曲线**：日常 → 隐约不安 → 灾年 → 成片的讣告 → 村子空掉。

---

## 2. 音乐的任务（三条原则）

| 原则 | 意思 | 反例 |
|---|---|---|
| **① 它是「地方」，不是「角色」** | 像在听一个村子呼吸，不像在听一个人在演奏 | 一段悲情二胡独奏，会让玩家觉得「音乐在替我哭」 |
| **② 不能抢讣告的注意力** | 玩家在读字的时候，音乐必须退到背景 | 有明显主旋律、有人声、有突然的强弱变化 |
| **③ 必须能循环 20 分钟** | 一局 10 分钟，玩家可能连开两局 | 前 15 秒很抓耳、后面越来越吵；结尾有明确终止感 |

**一句话总结**：**少即是多。** 宁可「好像没有音乐」，也不要「音乐在说话」。

## 3. 交付清单

### P0 · 必须有（截止前必须交）

| # | 交付物 | 时长 | 说明 |
|---|---|---|---|
| 1 | **主循环 · 基础层**（A） | **90 秒**，可无缝循环 | 全部时间的底噪 |
| 2 | **主循环 · 紧张层**（B） | **90 秒**，与 A 严格对齐 | 危机时叠上去，**不是另一首歌** |

> **A 和 B 必须是同一首曲子的两层**：同一个调、同一个速度、同一个小节起点。
> 我们要的是「把 B 的音量推上去」，不是「切到另一首」。

### P1 · 有更好（有余力再做）

| # | 交付物 | 时长 | 说明 |
|---|---|---|---|
| 3 | **丰年层**（C） | 90 秒，与 A 对齐 | 村子状态好时叠上去的一点点亮色，**极轻** |
| 4 | 开局长音（Sting） | 3–5 秒 | 游戏开始时的几声，之后接 A |

**没有 P1 也能上线。** P0 两条是硬要求。

## 4. 声音设计

### 4.1 配器（中国乡村 · 器乐 · 无人声）

**主奏（选 2–3 种，不要全上）**

- **埙（xun）** —— 首选。气声、空旷、不煽情。
- **箫（xiao）** —— 长音，慎用旋律。
- **古琴（guqin）** —— 单音、泛音、留白。
- **木鱼 / 木块** —— 极轻的、不规则的敲击，提供「有人在」的感觉。

**底色**

- 低频持续音（drone）：大提琴低音区 / 合成低频 pad，**音量很低**。
- 环境声：风、远处的犬吠、夜虫 —— 可以混进去，但**不要盖过乐器**。

**禁用清单**

| 不要 | 原因 |
|---|---|
| 人声、吟唱、哼鸣、念白 | 会抢讣告 |
| 战鼓、大鼓重击 | 这是村庄，不是战场 |
| 二胡主导的悲情旋律 | 太直白，会把游戏变成苦情戏 |
| 明显的五声音阶「仙侠风」 | 会显得廉价 |
| 突然的强弱对比、转调 | 循环里出现一次就会毁掉循环 |
| 电子鼓点 / 4/4 律动 | 这个游戏没有「节拍」 |

### 4.2 调性与速度

- **调**：D 小调 / D 羽调式（暗，但不沉重）
- **速度**：**50–60 BPM 的呼吸感，或者干脆没有明确节拍**
- **动态**：全程 **pp–mp**，不要有 f

### 4.3 90 秒里放什么

```
0–20s    低频 drone 铺开 + 一两声埙的长音
20–45s   古琴单音，间隔很大（4–8 秒一个音）
45–70s   木鱼/木块极轻地出现几下，然后消失
70–90s   回到 drone，留白 → 无缝接回 0s
```

**关键是「空」。** 每 10 秒里有 3–4 秒是几乎无声的，是正常的。

## 5. 三个状态与分层

游戏里只有三个音乐状态。**全部用 A/B 两层混出来**，不要单独做三条曲子。

| 状态 | 触发条件（程序判定） | 音乐怎么变 |
|---|---|---|
| **日常** | 默认 | 只有 **A** |
| **危机** | 平均恐惧 > 25 / 威信 < 60 / 闹饥荒 | **B 淡入**（0.5–1 秒），A 不变 |
| **丰年** | 人口上升、粮仓充足 | **C 淡入**（可选），B 淡出 |

> 死亡本身**不改变音乐**。死一个人是一声钟（音效），不是一段音乐。
> **音乐只反映「村子整体的状态」，不反映单次事件。**

### 分层要求（这条最容易做错）

- A 和 B **必须等长、同一小节起点**（第 0 采样必须对齐）
- B 单独听应该**几乎是空的** —— 只有低频 drone + 极轻的鼓/弦
- A + B 叠起来才是「危机」，**B 不能自带旋律**
- 交付时请分成**两个独立文件**，不要混成一条

## 6. 技术规格

| 项 | 要求 |
|---|---|
| 母带 | **WAV · 48 kHz · 24 bit · 立体声** |
| 交付格式 | 另给一份 **OGG Vorbis（质量 5–6）** |
| 响度 | **−18 LUFS**（整体），真峰值 **≤ −1 dBTP** |
| 循环 | **首尾无缝**：结尾的混响尾巴要能接上开头；不要有淡出 |
| 命名 | `bgm_main_A`, `bgm_main_B`, `bgm_main_C` |
| 结构 | **两个文件从同一秒开始**（同一小节），方便程序叠放 |
| 音质 | 不要有底噪、爆音、突然的静音断层 |

> **如果做无缝循环有困难**：宁可交一条「首尾各留 2 秒空白」的版本，
> 并注明循环点，我们在引擎里切。**不要自己加淡入淡出。**

## 7. 可以直接用的 AI 提示词

### 7.1 主循环 A（基础层）

```
Slow, sparse Chinese rural ambient music for a quiet village simulation game.
Instrumentation: xun (clay ocarina) long tones, distant xiao flute, solo guqin
single notes with long silences, very low sustained cello drone.
Tempo: 52 BPM, loose, no clear beat. Key: D minor / D aeolian.
Mood: calm, empty, slightly uneasy, never sentimental.
No vocals, no humming, no drums, no percussion hits, no melody hook,
no dramatic swells, no key changes.
Very low dynamic range (mostly pp to mp). Seamless 90-second loop.
```

**负面提示词：**

```
vocals, choir, humming, spoken word, erhu solo, epic drums, war drums,
taiko, synthwave, EDM beat, pentatonic cliché, xianxia, dramatic strings,
sudden dynamic change, key change, fade out, reverb tail cut
```

### 7.2 紧张层 B（危机）

```
Same key (D minor), same tempo (52 BPM), same 90-second length,
aligned to the same bar as the main layer.
Only: a very low sub-bass drone, a distant low bowed string swell,
and extremely sparse, quiet, irregular wooden knocks (muyu).
No melody, no flute, no guqin.
Mood: pressure, dread, something approaching.
Very quiet, mostly a low bed. Seamless loop.
```

> **生成技巧**：B 最好在 A 的同一个工程/同一次生成里做分轨，
> 或者用 A 的同一个 seed + 「remove melody, keep drone」的提示词。
> **不要重新写一首**。

### 7.3 丰年层 C（可选）

```
Same key and tempo as the main layer, 90 seconds, aligned.
Only: very soft guqin harmonics, a single distant bell, and a faint
warm pad. No melody line longer than three notes. Uplifting but restrained,
almost imperceptible. Seamless loop.
```

## 10. 验收标准

我们会按这五条验收，**全部是听感**：

- [ ] **循环 5 遍听不出接缝**
- [ ] **连续听 10 分钟不烦**（这条最重要）
- [ ] A + B 叠起来时，能感觉到「有事要发生」，但**说不出音乐在演什么**
- [ ] 把音量调到刚好能听见，**不影响读屏幕上的字**
- [ ] 没有**人声**、没有**明显主旋律**、没有**突然的强弱变化**
