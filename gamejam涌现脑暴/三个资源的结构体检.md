# 恐惧 / 税库 / 威信 —— 三个资源为什么是死的

> 你说后面的机制会**着重利用这三个**，所以我先把它们各自的"进水管和出水管"全查了一遍。
> **数据来自 10.14 构建的实测**（测试台：30 年 × 120 种子 × 每月采样）。
>
> 结论：**三个都是死的，但死法完全不同 —— 所以要接的管子也不一样。**

---

## 0. 一句话

```
恐惧  = 弹簧，不是蓄水池 —— 衰减太快，来源补不上，而且 11 条法条的门槛高过它的实际上限
税库  = 一次性收入 —— 唯一进项依赖"村民金币"，而金币只减不增
威信  = 单调爬升然后顶死 —— 上限 300 太低，而且它和恐惧之间那根管子太细
```

---

## 1. 恐惧：弹簧，不是蓄水池

### 实测

```
平均恐惧 6 – 23（平均 8.5）      个人最高 46
死线：恐惧 ≥ 99 → 死
```

**从来没接近过死线。**

### 机制（`AdvanceNeeds`，每 32 tick 一次）

```csharp
if (tick % 32 == 0) {
    int num4 = 0;
    if (HasLaw(4) && fear > 45) num4++;      // 恐惧蔓延
    if (HasLaw(6) && fear > 40) num4 -= 2;   // 安抚
    if (HasLaw(10))             num4--;      // 宵禁
    if (num4 == 0) {                          // ★ 没有法条在动它 → 往个人基准回落
        num5 = 12;                            //   普通
        if (怯懦)  num5 += 18;                //   → 30
        if (果决)  num5 -= 7;                 //   → 5
        if (惊魂)  num5 += 10;                //   → 22
        if (fear > num5) num4 = -1;
    }
    if (num4 != 0) fear = clamp(fear + num4, 0, 99);
}
```

### ★ 关键数字

```
不加法条时的衰减 = −1 / 32 tick = −91 / 年
→ 要维持恐惧不降，每年必须补 91 点
```

### 为什么补不上

**30 条法条碰恐惧，但分两类，都有问题：**

**① 11 条的条件是「恐惧已经很高」—— 而它到不了**

| 法条 | 条件 |
|---|---|
| 7 私刑倾向 | 自己恐惧 > 60 |
| 35 祭祀 | 3 人恐惧 > 50 |
| 47 整肃 | 3 人恐惧 > 50 |
| 37 立威 | 3 人恐惧 > 60 |
| 64 刑戮 | 3 人恐惧 > 60 |
| 34 诛心 | 3 人恐惧 > 65 |
| 18 起义豁免 | 3 人恐惧 > 70 |
| 22 瘟疫隔离 | 3 人恐惧 > 80 |
| 50 示众 | 3 人恐惧 > 80 |
| 36 逐客 | 3 人恐惧 > 85 |

**实测个人最高 46 —— 上面这些门槛一个都摸不到。这些法条永远不会触发。**

> **鸡生蛋：恐惧上不去 → 这些法条不触发 → 恐惧更上不去。**

**② 无条件能加的最强一条，速率也不够**

| 法条 | 加 | 条件 | 大约能给多少 |
|---|---|---|---|
| 16 连坐 | +6 | 邻居本 tick 死 | 30 年约 181 次死亡 × 相邻 2 人 × 6 ≈ **72 / 年** |
| 68 株连 | +8 | 邻居本 tick 死 | 同上，≈ 96 / 年（但和 16 抢同一个条件）|
| 67 阋墙 | +5 | **你和邻居都饿 > 60** | 最高饥饿 67 → 极少 |
| 2 饥则抢 | +3 | 饿 > 55 | 少 |
| 32 觊觎 | +4 | 饿 > 70 | 几乎不会 |

**最强的连坐 ≈ 72/年 < 衰减 91/年。** 补不上。

### ★ 要接它，改这三个之一

1. **衰减速率**（−1/32 调慢）
2. **个人基准**（现在 12，太低）
3. **那 11 条法的门槛**（从 60/70/80 降到恐惧实际能到的区间）

**最省事的是第 3 条** —— 不用动平衡，只是把 11 条死法条救活。

## 2. 税库：一次性收入，然后就死了

### 实测

```
税库 27 – 48（平均 47.9），30 年几乎不变
```

### 机制

**默认三法（济贫 / 耕作 / 税收）里，唯一动税库的是「税收」：**

```csharp
// 每 240 tick，对每个村民
if (HasLaw(3) && villagerGold[index] > 60) {
    villagerGold[index] -= 12;
    granaryFood += 3;
    treasuryGold += 3;
}
```

**★ 问题：进项依赖「村民金币 > 60」，而村民金币只减不增。**

```
开局金币 8–97 → 被榨一次 −12 → 再榨一次 −12 → …
97 → 85 → 73 → 61 → 49   ← 低于 60，从此再也榨不出
```

而且新生儿金币是 **0**。所以：

> **每个村民一辈子只能贡献 1–3 次税，全村榨干之后就再没有进项了。**

**默认法条组里还没有任何消耗** —— 所以税库是"填一次就停"。

### 另外 11 条碰税库的法条

`盐铁专卖 +6/240t`、`买粮 +30`、`捐纳 +20`、`丁税 +4`、`售粮 +4`、`平粜 −40`、`威权 −8`、`常平 −6`……

**默认组一条都没装。** 而且其中唯一有周期性的 `盐铁专卖` 也只有 +6/240t。

### ★ 要接它，改这两个之一

1. **给一个周期性、不依赖村民存量的进项**（按人口、按耕地、按存活年数）
2. **给它一个消耗口**（现在默认组零消耗）

## 3. 威信：单调爬升，然后顶死

### 实测

```
威信 0 – 300（平均 280.7）
★ 89% 的采样点顶在 300   ← 上一版是 50%
```

### 机制（每 60 tick）

```csharp
num8 = 人口 / 4 + Math.Max(0, 30 - 平均恐惧) / 10;
威信 = 威信 - 3 × 法条数 + num8;
```

### 为什么单调爬升

默认三法、人口 38：
```
+9.5（人口/4 = 9，恐惧项 = 0~2）
-9  （3 条法 × 3）
= 净 +0.5 / 60 tick
× 30 年约 360 次 = +180
100（开局）+ 180 = 280   ← 正好对上实测
```

**只要玩家装的法条数 ≤ 3，威信就是单增的。** 顶到 300 只是时间问题。

### ★★ 重点：恐惧 → 威信 那根管子已经接好了，但太细 ★★

```csharp
Math.Max(0, 30 - 平均恐惧) / 10
```

| 恐惧实际范围 | 这一项的值 |
|---|---|
| 6（很好）| (30−6)/10 = **2** |
| 23（最差）| (30−23)/10 = **0** |

**再看它旁边的 `人口/4`：人口 38 → 9。**

```
人口项   9
恐惧项   0–2      ← 只占 0–20%，而且几乎不变
```

**所以"恐惧低 → 威信涨得快"这个设计意图，代码里是有的，但量级完全没有体现出来。**

### ★ 要接它，改这两个之一

1. **把 `30` 挪到恐惧实际会到达的位置**（现在恐惧常年 < 30，所以永远落在"好"的那一侧）
   —— 比如改成 15 或 12，让恐惧的整个活动区间都落在阈值两侧
2. **放大这一项的系数**（现在 `/10`，最多给 2 点）

> **如果新机制打算用「恐惧」驱动「威信」，这是第一个要改的地方 ——**
> 否则你新加的机制会接在一根**几乎不过水**的管子上。

## 4. 三条通用结论

| | 恐惧 | 税库 | 威信 |
|---|---|---|---|
| **实测范围** | 6–23（个人 46）| 27–48 | 0–300 |
| **30 年走势** | 回中（弹簧）| 填满即停 | 单调爬到顶 |
| **死因** | **衰减 91/年，来源最多补 72/年** | **进项依赖枯竭的资源** | **上限太低 + 只增不减** |
| **死线（99）可达？** | ❌ 到不了 | — | — |
| **相关法条** | 30 条，其中 **11 条门槛高于实际上限** | 12 条，默认组全没装 | 8 条 |
| **★ 新机制该接在哪** | 衰减 / 基准 / **那 11 条的门槛** | **周期性进项** 或 **消耗口** | **上限** 和 **恐惧项那个 30** |

---

## 5. 建议：动手加机制之前，先做这三个小改

**这三条都不是"调平衡"，是"把管子接上"—— 不改数值，改的是死掉的那几行。**

| # | 改什么 | 一句话 | 工时 |
|---|---|---|---|
| 1 | **把 11 条恐惧法条的门槛降下来** | 从 60/70/80 降到恐惧实际能到的区间（比如 20–35）。**不用碰平衡，只是让它们能被触发** | 0.1 |
| 2 | **给税库一个周期性进项** | 不依赖村民金币。比如 `每 240 tick 按人口 +1` | 0.1 |
| 3 | **威信公式里那个 `30` 改掉** | `Math.Max(0, 30 - 平均恐惧)` → 让恐惧的整个活动区间跨越阈值。**这是恐惧和威信之间唯一的那根管子** | 0.05 |
| | | | **≈0.25 天** |

**做完再往上加新机制** —— 不然新机制会接在三个不通水的管子上，**测出来又是"没影响"**。

---

## 6. 一句话

> **恐惧、税库、威信现在都是死的，但死法不同：**
> **恐惧是弹簧（补不上），税库是一次性（填完就停），威信是单增（顶死上限）。**
>
> **而恐惧和威信之间那根管子已经在代码里了 —— 只是它的量级是 0–2，对面的人口项是 9。**
> **你要接的新机制，多半会接在这根管子上。先把它通开。**
